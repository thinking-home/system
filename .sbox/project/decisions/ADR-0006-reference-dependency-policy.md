# Автоматическое определение зависимостей

## Правило

Зависимости и версии задаются обычными PackageReference/ProjectReference. Плагины распознаются по метаданным DLL; обычные библиотеки приватные по умолчанию. Общая библиотека отмечается ThinkingHomeShared="true" на той же ссылке. ThinkingHomeDependency не используется.

Платформа определяется общим API. Плагины и платформенные пакеты нельзя помечать shared. Для встроенных непакетных библиотек сохраняется ThinkingHomeEmbedded.

## Контекст и обоснование

Маркер целевой сборки уже определяет плагин. Перечисление приватных библиотек дублировало ссылки проекта. Однако намерение сделать библиотеку общей нельзя однозначно вывести из DLL: автоматически повышая видимость, мы скрыли бы случайные утечки типов в публичный API.

## Последствия

В метаданные DLL переносятся только явные отметки shared. Общий targets читает PackageId отмеченных ProjectReference через оценку SDK, без отдельной сборки или команды подготовки. Имена проектов и DLL не используются вместо package ID.

Планировщик ищет зависимость сначала в репозиториях плагинов и только при отсутствии ID переходит к источникам библиотек. Скачанный пакет обязан подтверждать свою категорию маркером. Несовместимость версии, повреждение и недоступность источника не разрешают fallback. Корнями могут быть только плагины.

При locked-восстановлении категория восстанавливается из метаданных зафиксированных архивов без поиска. При локальном запуске используются подключённые реализации и установленные пакеты. Скопированная рядом DLL плагина сама по себе его не подключает. Одна активная версия каждого плагина и проверка циклов сохраняются.

Приватные типы запрещены в публичном контракте. Обнаружение утечки не меняет категорию библиотеки. Статическая проверка не отслеживает обмен значениями через object и динамические каналы.

## Как проверяется

Проверки упаковки, планирования, locked-восстановления и локальной загрузки охватывают приватные и shared-библиотеки, автоматическое распознавание зависимых плагинов, различающиеся PackageId и имена DLL, конфликты версий и циклы, запрет shared на плагине и отказ от fallback при повреждённом или недоступном источнике.
