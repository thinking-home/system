# Совместимость плагина через обычную зависимость от ядра

## Правило

Плагин использует обычную зависимость от `ThinkingHome.Core.Plugins`. Отдельного диапазона совместимости с версией ThinkingHome в свойствах проекта и манифесте DLL нет.

Для пакета диапазон версии ядра берётся из nuspec, который создаёт стандартная упаковка NuGet из PackageReference/ProjectReference. Для локального подключения используется разрешённая версия из стандартного deps.json сборки: для предоставляемого хостом ядра это нижняя граница. Дополнительно проверяются идентичности сборок и ссылки на типы.

Ядро предоставляет хост. Менеджер проверяет требование плагина относительно этой версии, не устанавливает второе ядро в область плагина и не запускает код при несовместимости. Снимок платформы в lock-файле по-прежнему нужен для воспроизводимости, включая версии и хеши её библиотек.

## Контекст

Плагин компилируется против PluginBase и API ядра. Зависимость описывает потребность плагина в этом API; пакет или результат сборки переносит эту информацию для проверки на целевом хосте.

## Обоснование

Обычная зависимость является единственным источником требований к версии ядра. Отдельный диапазон версии всей системы дублировал бы ограничение и требовал согласованного обновления двух деклараций.

## Последствия

При необходимости верхней границы автор задаёт её в обычной NuGet-зависимости. Из deps.json локальной сборки нельзя восстановить исходную верхнюю границу: он содержит выбранные версии. Автоматической гарантии поведенческой совместимости любых будущих версий ядра это правило не даёт.

## Как проверяется

Тесты планирования проверяют отклонение несовместимой версии ядра по nuspec и принятие версии, разрешённой обычным диапазоном. Тест локального запуска проверяет отказ по зависимости ядра из deps.json. Упаковка, установка, locked-восстановление и проверка хоста входят в ThinkingHome.Packaging.Tests.
