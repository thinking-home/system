# Общие NuGet-источники

## Правило

Конфигурация содержит единственный упорядоченный массив `sources` с адресами NuGet V3 service index. Один источник может содержать плагины и обычные библиотеки. `pluginSources`, `librarySources` и параметр категории в API/CLI источников удалены без поддержки старого формата.

Категория конкретной версии определяется после скачивания по существующим метаданным `ThinkingHome.Plugin.*` базовых DLL в `lib/net10.0/`. Корректный манифест означает плагин, отсутствие маркера — обычную библиотеку. Некорректный или неоднозначный манифест и несовпадение identity с nuspec вызывают ошибку. Код DLL не выполняется. Имя пакета, NuGet-теги и адрес источника не определяют категорию.

Первый источник с нужным ID закрепляет список версий; версии из разных источников не объединяются. Отсутствие ID допускает поиск дальше, сетевые ошибки и повреждение пакета останавливают операцию. Разные байты одной identity в настроенных источниках запрещены.

## Контекст

nuget.org и другие общие NuGet V3-серверы содержат пакеты обоих типов. Наличие ID в таком источнике не позволяет определить плагин. Потребителей старой конфигурации нет; адаптер совместимости не нужен.

## Обоснование

Маркер DLL уже является проверяемым контрактом ThinkingHome и сохраняется внутри обычного nupkg. Единый список устраняет классификацию по месту хранения и позволяет использовать публичный NuGet без специального сервера или дополнительных соглашений об именах.

## Последствия

Планировщик учитывает категорию выбранных версий отдельно в каждой ветви поиска. Обнаруженный плагин объединяет требования потребителей в один узел. Возврат к другой версии учитывает её собственные метаданные. Один ID нельзя одновременно использовать как плагин и библиотеку. Корнями могут быть только плагины; правила одной версии плагина, private/shared-областей и запрета shared на плагине сохраняются.

Lock сохраняет категорию, источник, версию и хеш. Восстановление и проверка установленного состояния сверяют категорию с метаданными архива. Зафиксированный источник должен присутствовать в `sources`; его новый приоритет не меняет выбор при восстановлении.

Специализированный ThinkingHome.Repository по-прежнему принимает только плагины. Общий источник для менеджера может быть любым совместимым NuGet V3-сервером. Публикация инструментов как dotnet tool и публикация пакетов на nuget.org не входят в это изменение.

## Как проверяется

Тесты охватывают определение категории без исполнения DLL, некорректные маркеры и несколько манифестов, единый источник и его приоритеты, отклонение старой конфигурации, библиотеку в корне, подбор версий со сменой категории и запрет смешения категорий одного ID. Проверяется подмена категории в lock. Сквозные сценарии используют общий HTTP NuGet V3-источник для установки через CLI, восстановления и запуска плагинов хостом.
