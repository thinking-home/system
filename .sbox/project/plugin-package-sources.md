# Результат этапа источников и репозитория

Третий этап [плана MVP](decisions/ADR-0003-plugin-package-management-stages.md) реализован как отдельные [сервер репозитория](../../ThinkingHome.Repository/README.md) и [клиент источников](../../ThinkingHome.PackageSources/README.md). Оба проекта добавлены в решение.

Сервер индексирует верхний уровень папки nupkg при запуске, проверяет структуру и манифесты DLL без исполнения кода и без зависимостей плагина, предоставляет service index и PackageBaseAddress/3.0.0. Пакеты выдаются из неизменяемого снимка в памяти; журнал SHA-512 защищает известные ID/версии от незаметной замены при перезапуске. Новые файлы становятся видимыми после перезапуска.

Клиент разделяет pluginSources и librarySources, выбирает первый источник с нужным ID и закрепляет за ним список версий. 404 пакета допускает поиск дальше; недоступность сервера не подменяется отсутствием пакета. Перед сохранением проверяются identity, признак плагина при соответствующем запросе и совпадение содержимого одной версии между источниками группы. Полученные источник, метаданные, байты и SHA-512 доступны планировщику этапа 4.

Проверка сервера структурная: он не располагает выбранным графом зависимостей и не утверждает, что публичный API плагина совместим с конкретным окружением. Полная статическая валидация из второго этапа повторяется после разрешения графа на этапе 4.

## Проверки

13 октября 2026 года на Windows x64 прошли все 42 теста упаковки и источников. Выполнен HTTP-цикл на настоящем локальном Kestrel: версия, скачивание исходного архива, nuspec, HEAD, 404 и неизменяемость снимка. Тесты также проверяют восстановление журнала после ошибки, отказ в подмене опубликованной версии, игнорирование staging-папок, разделение источников, приоритет, конфликты, ошибки сети и сохранение существующих файлов.

Клиент отдельно скачал Newtonsoft.Json 13.0.3 с настоящего nuget.org в `artifacts/source-downloads`. Пакет не добавлялся в проекты и не устанавливался в приложение; пробный архив удаляется при подготовке к коммиту. Linux-прогон не выполнялся.
