## Конфигурация

Настройки приложения можно задать в файле `appsettings.json`. Если указано название окружения в переменной `THINKINGHOME_ENVIRONMENT`, то дополнительно будут подключены настройки из файла `appsettings.{THINKINGHOME_ENVIRONMENT}.json` (если такого файла нет, приложение запустится без него).

Файлы настроек приложение ищет в каталоге хоста либо в каталоге, указанном через `--app`. Относительный путь `--app` считается от текущего рабочего каталога процесса.

Вы можете передать дополнительные параметры конфигурации через [переменные окружения](https://docs.microsoft.com/ru-ru/dotnet/core/extensions/configuration-providers#environment-variable-configuration-provider) с префиксом `THINKINGHOME_`. В качестве иерархического разделителя используйте `__`.

Например, чтобы передать параметр `plugins:ThinkingHome.Plugins.Mail.MailPlugin:fromMail` укажите значение для переменной окружения `THINKINGHOME_plugins__ThinkingHome.Plugins.Mail.MailPlugin__fromMail`

## Запуск плагинов

Этот проект — потребительский хост без ссылок на плагины. Он использует проверенную установку пакетного менеджера и необязательный `plugins.local.json` с путями к DLL. Для сборки всей системы и подготовки локальных подключений используется `ThinkingHome.Local.proj`; стартовый проект в IDE — этот же Console.

Каталог установки и настроек можно передать через `--app`:

```shell
dotnet run --project ThinkingHome.Console -- --app ./application
```

Установка зависимостей, отладка в IDE и запуск монорепозитория описаны в [трёх сценариях запуска](../ThinkingHome.PackageRuntime/README.md).

Настройки из `appsettings.Development.json` дополняют `appsettings.json` при `THINKINGHOME_ENVIRONMENT=Development`. Списки объединяются по индексам. Состав плагинов определяется проверенным графом установки и локальных подключений; поле `assemblies` не используется.

При обычной сборке локальный `appsettings.Development.json` копируется для отладки, но в результат `dotnet publish` не включается. Настройки целевой установки размещаются отдельно в каталоге приложения.

В файлах настроек можно использовать комментарии — провайдер конфигурации их игнорирует.

## Параметры командной строки

Параметры декларативно описаны в `Main` и разбираются пакетом System.CommandLine:

- `--app <каталог>` — каталог установки и настроек; по умолчанию используется каталог хоста.
- `--check` — проверить план и загрузку типов без запуска плагинов.
- `--help` / `--version` — показать справку или версию без загрузки плагинов.

Справка и успешное выполнение возвращают код 0; ошибки аргументов или запуска — код 1.

Хост и отдельный менеджер автоматически определяют платформу через [общий API и контракт совместной поставки](../ThinkingHome.Platform/README.md).
