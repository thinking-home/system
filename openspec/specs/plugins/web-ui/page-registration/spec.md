# plugins/web-ui/page-registration Specification

## Purpose

Даёт плагинам единый способ зарегистрировать раздел веб-интерфейса и отдаёт браузеру всё необходимое для его загрузки: общий HTML-документ, JS-бандл раздела, общие vendor-модули/стили и локализацию.

## Requirements

### Requirement: Регистрация раздела веб-интерфейса
Метод плагина, помеченный атрибутом `[ConfigureWebUi]`, SHALL иметь возможность зарегистрировать раздел веб-интерфейса по URL через билдер конфигурации, указав JS-бандл раздела (с опциональными предсжатыми gzip- и brotli-копиями). Регистрация SHALL выполняться на этапе конфигурации веб-сервера, до начала обработки запросов.

#### Scenario: Плагин регистрирует раздел
- **WHEN** метод плагина с атрибутом `[ConfigureWebUi]` регистрирует раздел по URL `U` с JS-бандлом `B`
- **THEN** после запуска приложения по адресу `U` доступен HTML-документ веб-интерфейса, а бандл `B` доступен по вычисленному для этого раздела адресу JS-файла

### Requirement: Общий HTML-документ
По корневому адресу (`/`) и по адресу документа каждого зарегистрированного раздела SHALL отдаваться один и тот же HTML-документ веб-интерфейса. Документ SHALL содержать import map, построенную из общего манифеста vendor-модулей (соответствие имени импорта его файлу), и подключение файлов стилей, перечисленных в этом же манифесте.

#### Scenario: Документ раздела и корневой документ совпадают
- **WHEN** запрашивается корневой адрес `/` и адрес документа зарегистрированного раздела
- **THEN** оба ответа содержат одинаковый HTML-документ с одинаковой import map и одинаковым набором подключённых стилей

### Requirement: Раздача vendor-модулей и стилей с предсжатыми копиями
Файлы vendor-модулей и стилей, перечисленные в манифесте, SHALL раздаваться по адресам, на которые ссылается import map и подключение стилей документа. Если манифест заявляет для файла предсжатые gzip- и/или brotli-копии, они SHALL быть зарегистрированы и использоваться при раздаче наравне с раздачей файлов раздела и JS-бандла главного клиента приложения.

#### Scenario: Vendor-модуль доступен по адресу из import map
- **WHEN** браузер запрашивает vendor-модуль по адресу, указанному в import map документа
- **THEN** сервер отдаёт содержимое этого модуля (или его предсжатую копию, если браузер её принимает)

### Requirement: Эндпоинт метаданных веб-интерфейса
Веб-интерфейс SHALL предоставлять эндпоинт `/api/webui/meta`, возвращающий для каждого зарегистрированного раздела адрес документа, адрес его JS-бандла и идентификатор его языкового пакета, а также конфигурацию клиента: текущий язык сервера и параметры подключения к шине сообщений (маршрут, имена клиентского и серверного методов, таймаут переподключения), опубликованные `plugins/web-server/message-bus` — эти значения SHALL браться из публикации шины сообщений, а не задаваться отдельно.

#### Scenario: Клиент получает список разделов и конфигурацию шины
- **WHEN** клиент запрашивает `/api/webui/meta`
- **THEN** в ответе перечислены все зарегистрированные разделы (адрес документа, адрес JS-бандла, идентификатор языкового пакета) и конфигурация подключения к шине сообщений, совпадающая со значениями, опубликованными `plugins/web-server/message-bus`

### Requirement: Эндпоинт локализации раздела
Веб-интерфейс SHALL предоставлять эндпоинт `/api/webui/lang`, возвращающий по идентификатору языкового пакета (`id`) все локализованные строки плагина, зарегистрировавшего хотя бы один раздел с этим идентификатором, на текущем языке сервера. Запрос с идентификатором, не принадлежащим ни одному плагину с зарегистрированным разделом, SHALL завершаться ошибкой.

#### Scenario: Клиент запрашивает строки локализации раздела
- **WHEN** клиент запрашивает `/api/webui/lang?id={langId}` с идентификатором языкового пакета зарегистрированного раздела
- **THEN** в ответе возвращаются все локализованные строки плагина, которому принадлежит этот раздел

#### Scenario: Запрос локализации с неизвестным идентификатором
- **WHEN** клиент запрашивает `/api/webui/lang` с идентификатором, не соответствующим ни одному зарегистрированному разделу
- **THEN** запрос завершается ошибкой, и строки локализации не возвращаются
