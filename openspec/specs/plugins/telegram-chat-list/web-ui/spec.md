# Web Ui Specification

## Purpose
Добавляет в веб-интерфейс раздел для просмотра списка чатов Telegram, сохранённых контрактом `plugins/telegram-chat-list/chat-tracking`, используя HTTP API `plugins/telegram-chat-list/http-api`.

## Requirements

### Requirement: Зависимость от HTTP API списка чатов
`TelegramChatList.WebUi` SHALL получать все данные о чатах через HTTP API `plugins/telegram-chat-list/http-api` и SHALL не обращаться к базе данных напрямую; для корректной работы раздела `TelegramChatList.WebUi` SHALL быть подключён вместе с плагином, предоставляющим этот API.

#### Scenario: Раздел использует HTTP API списка чатов
- **WHEN** пользователь открывает раздел `TelegramChatList.WebUi`
- **THEN** данные для раздела запрашиваются через HTTP API `/api/telegram-chat-list/web-api/list`

### Requirement: Раздел списка чатов
Страница `/telegram-chat-list` SHALL отображать список сохранённых чатов, показывая для каждого чата все поля записи в ответе API: `id`, `login`, `chatId`, `firstName`, `lastName` и `date`. Раздел SHALL быть доступен только для чтения: действий добавления, редактирования и удаления чатов раздел SHALL не предоставлять.

#### Scenario: Открытие списка чатов
- **GIVEN** в системе есть сохранённые записи о чатах
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** отображается список чатов, в котором для каждого чата показаны `id`, `login`, `chatId`, `firstName`, `lastName` и `date`

#### Scenario: Отсутствие действий над чатами
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** в разделе нет действий добавления, редактирования и удаления чата

### Requirement: Порядок вывода чатов
Раздел SHALL выводить чаты в том порядке, в котором они пришли в ответе API, и SHALL не переупорядочивать их (порядок по убыванию `date` задаёт `plugins/telegram-chat-list/http-api`). Средств изменить порядок вывода раздел SHALL не предоставлять.

#### Scenario: Список выводится в порядке ответа API
- **GIVEN** API вернул несколько записей о чатах в определённом порядке
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** чаты отображаются в том же порядке, в каком они пришли в ответе API

#### Scenario: Изменить порядок вывода нельзя
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** в разделе нет средств изменить порядок вывода чатов

### Requirement: Состояние пустого списка чатов
Если в ответе API нет ни одной записи о чате, раздел SHALL отображать состояние пустого списка: заголовок раздела и на месте списка — сообщение о том, что чатов пока нет. Пустой список чатов (в том числе строка заголовков колонок) SHALL не отображаться, и пустая область без пояснения SHALL не оставаться.

#### Scenario: Сообщение вместо пустого списка
- **GIVEN** API вернул пустой список чатов
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** на месте списка отображается сообщение о том, что чатов пока нет

#### Scenario: Пустой список не отображается
- **GIVEN** API вернул пустой список чатов
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** список чатов со строкой заголовков колонок не отображается, а заголовок раздела остаётся на экране

### Requirement: Отсутствующие значения полей чата
Если поля `login`, `firstName` или `lastName` пришли в ответе API как `null`, раздел SHALL отображать в соответствующих ячейках списка отметку об отсутствии значения, а не пустое место и не текст `null`.

#### Scenario: Поле чата не заполнено
- **GIVEN** у записи о чате поле `login`, `firstName` или `lastName` возвращается как `null`
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** в ячейке этого поля отображается отметка об отсутствии значения

### Requirement: Ошибка загрузки списка чатов
Если запрос списка чатов завершился ошибкой, раздел SHALL показать пользователю уведомление об ошибке загрузки и SHALL не отображать список чатов.

#### Scenario: Запрос списка чатов завершился ошибкой
- **WHEN** запрос `/api/telegram-chat-list/web-api/list` завершается ошибкой
- **THEN** пользователю показывается уведомление об ошибке загрузки данных, а список чатов не отображается

### Requirement: Переход в раздел списка чатов с корневой страницы
На корневой странице веб-интерфейса SHALL быть ссылка на раздел списка чатов, переход по которой открывает `/telegram-chat-list`.

#### Scenario: Переход на раздел с корневой страницы
- **WHEN** пользователь открывает корневую страницу веб-интерфейса и переходит по ссылке на список чатов
- **THEN** открывается раздел `/telegram-chat-list`

### Requirement: Локализация раздела списка чатов
Заголовок раздела, подписи полей списка, сообщение о пустом списке и уведомление об ошибке загрузки SHALL отображаться на текущем языке сервера; язык текстов по умолчанию — английский, для русского языка SHALL быть перевод.

#### Scenario: Раздел на русском языке
- **GIVEN** текущий язык сервера — русский
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** заголовок раздела и подписи полей списка отображаются на русском языке

#### Scenario: Сообщение о пустом списке на русском языке
- **GIVEN** текущий язык сервера — русский, а API вернул пустой список чатов
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** сообщение о том, что чатов пока нет, отображается на русском языке
