# Web Ui Specification

## Purpose
Добавляет в веб-интерфейс раздел со списком чатов Telegram, сохранённых плагином учёта чатов, использующий HTTP API `plugins/telegram-chat-list/http-api`. Раздел предназначен только для просмотра.

## Requirements

### Requirement: Зависимость от HTTP API списка чатов
`TelegramChatList.WebUi` SHALL получать все данные о чатах через HTTP API `plugins/telegram-chat-list/http-api`; для корректной работы раздела `TelegramChatList.WebUi` SHALL быть подключён вместе с плагином, предоставляющим этот API.

#### Scenario: Раздел использует HTTP API списка чатов
- **WHEN** пользователь открывает раздел `TelegramChatList.WebUi`
- **THEN** данные для раздела запрашиваются через HTTP API `/api/telegram-chat-list/web-api/list`

### Requirement: Раздел списка чатов
Страница `/telegram-chat-list` SHALL отображать таблицу сохранённых записей о чатах, в которой для каждой записи показаны все поля ответа HTTP API: `id`, `chatId`, `login`, `firstName`, `lastName` и `date`. Записи SHALL отображаться в том порядке, в котором их вернул HTTP API, без пагинации, фильтров и переключения сортировки. Раздел SHALL быть доступен только для просмотра: действий создания, изменения и удаления записей SHALL не быть.

#### Scenario: Открытие списка чатов
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** отображается таблица сохранённых чатов, в которой у каждой записи показаны `id`, `chatId`, `login`, `firstName`, `lastName` и `date`

#### Scenario: Порядок записей в таблице
- **GIVEN** HTTP API вернул список записей о чатах
- **WHEN** отображается таблица чатов
- **THEN** записи идут в том же порядке, что и в ответе HTTP API

#### Scenario: Раздел не содержит действий изменения
- **WHEN** отображается таблица чатов
- **THEN** в разделе нет действий создания, редактирования или удаления записей

### Requirement: Отображение незаданных значений и пустого списка
Если поле записи (`login`, `firstName`, `lastName`) возвращено как `null`, раздел SHALL отображать в соответствующей ячейке прочерк вместо пустого места. Если список чатов пуст, вместо таблицы SHALL отображаться сообщение об отсутствии записей.

#### Scenario: Запись с незаданными полями
- **WHEN** в списке есть запись, у которой `login`, `firstName` или `lastName` равны `null`
- **THEN** в соответствующих ячейках таблицы отображается прочерк

#### Scenario: Пустой список чатов
- **WHEN** HTTP API вернул пустой список чатов
- **THEN** вместо таблицы отображается сообщение об отсутствии сохранённых чатов

### Requirement: Ошибка загрузки списка чатов
Если запрос списка чатов завершился ошибкой, раздел SHALL показать пользователю уведомление об ошибке загрузки данных и SHALL не отображать таблицу с частичными данными.

#### Scenario: Запрос списка завершился ошибкой
- **WHEN** запрос `/api/telegram-chat-list/web-api/list` завершается ошибкой
- **THEN** пользователю показывается уведомление об ошибке загрузки, а таблица чатов не отображается
