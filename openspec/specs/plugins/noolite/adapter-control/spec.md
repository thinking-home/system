# plugins/noolite/adapter-control Specification

## Purpose

Описывает API отправки команд адаптеру nooLite/nooLite-F для управления нагрузкой и RGB-лентой, доступное другим плагинам и сценариям.

## Requirements

### Requirement: Получение объекта управления адаптером (Open)
Плагин SHALL предоставлять метод `Open(fMode)`, возвращающий объект управления адаптером, привязанный к выбранному режиму отправки команд: `fMode = false` — стандартный режим nooLite, `fMode = true` — режим nooLite-F (с шифрованием и обратной связью). Метод SHALL быть доступен как API плагина для использования другими плагинами и SHALL быть зарегистрирован как скриптовая команда `noolite`, доступная сценариям согласно контракту `plugins/scripts/script-execution` — «Вызов методов плагинов из сценария (ScriptCommand)».

#### Scenario: Получение объекта в стандартном режиме
- **WHEN** вызывается `Open(false)`
- **THEN** возвращается объект управления адаптером, отправляющий команды в стандартном режиме nooLite

#### Scenario: Получение объекта в режиме nooLite-F
- **WHEN** вызывается `Open(true)`
- **THEN** возвращается объект управления адаптером, отправляющий команды в режиме nooLite-F

#### Scenario: Вызов из сценария
- **WHEN** сценарий вызывает `host.api.noolite(fMode)`
- **THEN** возвращается объект управления адаптером с тем же набором команд, что и для плагинов, но с именами методов в стиле camelCase (`on`, `off`, `setBrightness`, `temporarySwitchOn`, `changeLedColor`, `setLedColor`, `loadPreset`)

### Requirement: Включение и выключение нагрузки
Объект управления адаптером SHALL предоставлять методы `On(channel)` и `Off(channel)`, включающие и выключающие нагрузку в заданном канале.

#### Scenario: Включение нагрузки
- **WHEN** вызывается `On(channel)`
- **THEN** адаптеру отправляется команда включения нагрузки в указанном канале, в режиме, соответствующем выбранному при `Open`

#### Scenario: Выключение нагрузки
- **WHEN** вызывается `Off(channel)`
- **THEN** адаптеру отправляется команда выключения нагрузки в указанном канале, в режиме, соответствующем выбранному при `Open`

### Requirement: Установка яркости
Объект управления адаптером SHALL предоставлять метод `SetBrightness(channel, brightness)`, устанавливающий уровень яркости нагрузки в заданном канале.

#### Scenario: Установка яркости
- **WHEN** вызывается `SetBrightness(channel, brightness)`
- **THEN** адаптеру отправляется команда установки указанной яркости в указанном канале

### Requirement: Временное включение нагрузки
Объект управления адаптером SHALL предоставлять метод `TemporarySwitchOn(channel, minutes)`, включающий нагрузку в заданном канале на заданное количество минут. Длительность в минутах SHALL быть преобразована в единицы интервала, ожидаемые адаптером (12 единиц на минуту), перед отправкой команды.

#### Scenario: Временное включение на заданное время
- **WHEN** вызывается `TemporarySwitchOn(channel, minutes)`
- **THEN** адаптеру отправляется команда временного включения нагрузки в указанном канале с длительностью, пересчитанной из минут в единицы интервала адаптера

### Requirement: Управление цветом RGB-ленты
Объект управления адаптером SHALL предоставлять метод `ChangeLedColor(channel)`, переключающий цвет подключённой RGB-ленты на следующий из предопределённого набора, и метод `SetLedColor(channel, r, g, b)`, устанавливающий заданный цвет RGB-ленты по компонентам красного, зелёного и синего цвета.

#### Scenario: Переключение на следующий цвет
- **WHEN** вызывается `ChangeLedColor(channel)`
- **THEN** адаптеру отправляется команда смены цвета RGB-ленты в указанном канале на следующий из предопределённого набора

#### Scenario: Установка заданного цвета
- **WHEN** вызывается `SetLedColor(channel, r, g, b)`
- **THEN** адаптеру отправляется команда установки цвета RGB-ленты в указанном канале с заданными компонентами r, g, b

### Requirement: Применение сохранённого сценария освещения
Объект управления адаптером SHALL предоставлять метод `LoadPreset(channel)`, применяющий ранее запомненный сценарий освещения в заданном канале.

#### Scenario: Применение сценария освещения
- **WHEN** вызывается `LoadPreset(channel)`
- **THEN** адаптеру отправляется команда применения ранее запомненного сценария освещения в указанном канале

### Requirement: Обработка ошибок отправки команды
Перед отправкой каждой команды объект управления адаптером SHALL попытаться открыть соединение с адаптером. Если отправка команды (включая попытку открыть соединение) завершается исключением, оно SHALL быть перехвачено и записано в лог; исключение SHALL не пробрасываться вызвавшему коду.

#### Scenario: Ошибка при отправке команды
- **WHEN** отправка команды адаптеру завершается исключением
- **THEN** исключение записывается в лог и не пробрасывается вызвавшему коду
