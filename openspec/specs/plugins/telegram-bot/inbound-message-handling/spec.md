# plugins/telegram-bot/inbound-message-handling Specification

## Purpose

Приём входящих сообщений Telegram, авторизация отправителя по списку разрешённых логинов и диспетчеризация сообщения в обработчики, зарегистрированные другими плагинами.

## Requirements

### Requirement: Конфигурация плагина
Плагин SHALL получать из конфигурации API-токен бота (поле `token`) и список авторизованных логинов Telegram (поле `authorizedLogins`). Сравнение логина отправителя со списком авторизованных логинов SHALL выполняться без учёта регистра.

#### Scenario: Логин сравнивается без учёта регистра
- **WHEN** в `authorizedLogins` указан логин `USER2`, а сообщение получено от пользователя с username `user2`
- **THEN** отправитель считается авторизованным

### Requirement: Приём обновлений от Telegram
Плагин SHALL получать от Telegram API только обновления с новыми сообщениями (без учёта прочих типов обновлений) на протяжении своей работы и SHALL прекращать приём при остановке плагина.

#### Scenario: Приём сообщений во время работы плагина
- **WHEN** плагин запущен
- **THEN** плагин получает от Telegram API новые входящие сообщения

#### Scenario: Приём прекращается при остановке плагина
- **WHEN** плагин останавливается
- **THEN** плагин прекращает получать новые обновления от Telegram API

### Requirement: Разбор команды из текста сообщения
Плагин SHALL разбирать команду в начале текста сообщения: необязательные пробельные символы, символ `/`, далее последовательность из латинских букв, цифр, дефиса и подчёркивания. Разбор SHALL останавливаться на первом символе, не входящем в этот набор. Если текст сообщения не начинается (после пробельных символов) с `/`, либо текст отсутствует, команда SHALL считаться пустой строкой.

#### Scenario: Сообщение с одним словом
- **WHEN** текст сообщения — `/qwe`
- **THEN** распознанная команда — `qwe`

#### Scenario: Сообщение с несколькими словами
- **WHEN** текст сообщения — `/qwert lfklll`
- **THEN** распознанная команда — `qwert`

#### Scenario: Сообщение с пробелами перед командой
- **WHEN** текст сообщения начинается с пробельных символов и переводов строки, за которыми следует `/xxx ffff`
- **THEN** распознанная команда — `xxx`

#### Scenario: Разбор останавливается на неподдерживаемом символе
- **WHEN** текст сообщения — `/qwe-1_абв`
- **THEN** распознанная команда — `qwe-1_`

#### Scenario: Сообщение без команды
- **WHEN** текст сообщения — `qwert` (не начинается с `/`)
- **THEN** распознанная команда — пустая строка

#### Scenario: Отсутствующий текст сообщения
- **WHEN** у входящего сообщения отсутствует текст
- **THEN** распознанная команда — пустая строка

### Requirement: Событие о получении сообщения
Плагин SHALL предоставлять событие, которое возникает при получении каждого входящего сообщения — независимо от типа чата и от того, авторизован ли отправитель.

#### Scenario: Событие возникает для любого сообщения
- **WHEN** получено сообщение из группового чата или от пользователя, не входящего в `authorizedLogins`
- **THEN** событие о получении сообщения возникает с этим сообщением

#### Scenario: Ошибка одного подписчика не мешает другим
- **WHEN** один из подписчиков события выбрасывает исключение при обработке
- **THEN** исключение логируется, а остальные подписчики события вызываются как обычно

### Requirement: Авторизация отправителя для обработки команд
Плагин SHALL передавать сообщение в обработчики команд только если сообщение получено в личном чате (не групповом) и username отправителя присутствует в `authorizedLogins`. Сообщения из прочих чатов и от неавторизованных отправителей SHALL NOT передаваться в обработчики команд. Факт получения сообщения от неавторизованного отправителя в личном чате SHALL логироваться; для сообщений из групповых чатов такое логирование не выполняется.

#### Scenario: Сообщение из личного чата от авторизованного пользователя
- **WHEN** получено сообщение в личном чате от пользователя из `authorizedLogins`
- **THEN** сообщение передаётся в обработчики команд

#### Scenario: Сообщение из группового чата
- **WHEN** получено сообщение из группового чата
- **THEN** сообщение не передаётся в обработчики команд

#### Scenario: Сообщение от неавторизованного пользователя
- **WHEN** получено сообщение в личном чате от пользователя, отсутствующего в `authorizedLogins`
- **THEN** сообщение не передаётся в обработчики команд и факт получения логируется

### Requirement: Регистрация обработчиков команд плагинами
Плагин SHALL позволять другим плагинам регистрировать методы-обработчики входящих сообщений, отмеченные атрибутом с указанием команды. Метод, зарегистрированный с конкретной командой, SHALL вызываться для авторизованных сообщений, чья разобранная команда совпадает с указанной (включая пустую строку — для сообщений без команды). Метод, зарегистрированный без указания команды, SHALL вызываться для всех авторизованных сообщений независимо от разобранной команды.

#### Scenario: Обработчик для конкретной команды
- **WHEN** зарегистрирован обработчик для команды `test`, и авторизованное сообщение начинается с `/test`
- **THEN** этот обработчик вызывается с командой `test` и текстом сообщения

#### Scenario: Обработчик для сообщений без команды
- **WHEN** зарегистрирован обработчик для пустой команды, и авторизованное сообщение не содержит команды
- **THEN** этот обработчик вызывается с пустой командой

#### Scenario: Обработчик для всех сообщений
- **WHEN** зарегистрирован обработчик без указания команды
- **THEN** этот обработчик вызывается для каждого авторизованного сообщения независимо от его команды

#### Scenario: Обработчик не вызывается для чужой команды
- **WHEN** зарегистрирован обработчик для команды `test`, и авторизованное сообщение начинается с `/other`
- **THEN** этот обработчик не вызывается

#### Scenario: Ошибка одного обработчика не мешает другим
- **WHEN** один из вызываемых обработчиков команды выбрасывает исключение
- **THEN** исключение логируется, а остальные подходящие обработчики вызываются как обычно
