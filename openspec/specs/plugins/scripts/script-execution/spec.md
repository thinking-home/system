# plugins/scripts/script-execution Specification

## Purpose

Позволяет сохранять в системе JavaScript-сценарии и выполнять их — как сохранённые, так и переданные напрямую, — с доступом из сценария к API, предоставленному плагинами системы.

## Requirements

### Requirement: Выполнение сценария по тексту
Метод `ExecuteScript(string body, params object[] args)` SHALL выполнять переданный текст сценария на JavaScript, передавая в него `args` в качестве аргументов, и SHALL возвращать значение, переданное сценарием через `return`, или `null`, если сценарий не выполнил `return` или завершился ошибкой.

#### Scenario: Выполнение сценария с возвращаемым значением
- **WHEN** вызывается `ExecuteScript` с текстом сценария, который выполняет `return <значение>`
- **THEN** вызов возвращает это значение

#### Scenario: Сценарий не содержит return
- **WHEN** вызывается `ExecuteScript` с текстом сценария без команды `return`
- **THEN** вызов возвращает `null`

### Requirement: Выполнение сохранённого сценария
Метод `ExecuteScript(UserScript script, params object[] args)` SHALL выполнять текст переданного сохранённого сценария так же, как `ExecuteScript(string, object[])`. Метод `ExecuteScriptByName(string name, params object[] args)` SHALL найти в хранилище сценариев сценарий с указанным именем и выполнить его тем же образом; если сценарий с таким именем не найден (или найдено более одного), SHALL вернуться `null`, а информация об ошибке SHALL быть записана в лог.

#### Scenario: Выполнение по объекту UserScript
- **WHEN** вызывается `ExecuteScript` с ранее сохранённым `UserScript`
- **THEN** выполняется текст этого сценария с переданными аргументами

#### Scenario: Выполнение по имени, сценарий найден
- **WHEN** вызывается `ExecuteScriptByName` с именем существующего сценария
- **THEN** выполняется текст этого сценария с переданными аргументами

#### Scenario: Выполнение по имени, сценарий не найден
- **WHEN** вызывается `ExecuteScriptByName` с именем, для которого в хранилище нет сценария
- **THEN** вызов возвращает `null`, а в лог записывается ошибка

### Requirement: Хранение сценариев
Сохранённый сценарий SHALL представляться записью `UserScript` с полями `Id` (идентификатор), `Name` (имя, по которому сценарий можно найти через `ExecuteScriptByName` и вызвать из других сценариев через `host.scripts`) и `Body` (текст сценария на JavaScript).

#### Scenario: Хранение сценария
- **WHEN** сценарий сохраняется в системе
- **THEN** он представлен записью `UserScript` с идентификатором, именем и текстом

### Requirement: Аргументы и возвращаемое значение сценария
Внутри выполняемого сценария SHALL быть доступна константа `args`, содержащая переданные аргументы: при прямом запуске сценария — переданный массив аргументов, при запуске обработчиком сценарного события — параметры этого события. Объявление в коде сценария на верхнем уровне переменной с именем `args` SHALL приводить к ошибке синтаксиса. Команда `return <значение>` в коде сценария SHALL завершать его выполнение и передавать значение вызвавшему.

#### Scenario: Чтение args при прямом запуске
- **WHEN** сценарий запущен с аргументами через `ExecuteScript`/`ExecuteScriptByname`
- **THEN** константа `args` в сценарии содержит переданный массив аргументов

#### Scenario: Попытка объявить свою переменную args
- **WHEN** код сценария на верхнем уровне объявляет переменную с именем `args`
- **THEN** выполнение завершается ошибкой синтаксиса

### Requirement: Переменная meta в сценарии
Внутри выполняемого сценария SHALL быть доступна константа `meta`: если сценарий запущен как обработчик сценарного события — словарь строковых значений meta этого события, иначе — `undefined`. Объявление в коде сценария на верхнем уровне переменной с именем `meta` SHALL приводить к ошибке синтаксиса.

#### Scenario: meta при прямом запуске сценария
- **WHEN** сценарий запущен напрямую (не как обработчик события)
- **THEN** константа `meta` в сценарии равна `undefined`

#### Scenario: meta при запуске как обработчика события
- **WHEN** сценарий запущен как обработчик сценарного события с заданным словарём meta
- **THEN** константа `meta` в сценарии содержит этот словарь

### Requirement: Таймаут выполнения сценария
Максимальное время выполнения одного сценария SHALL задаваться параметром `executionTimeout` конфигурации плагина в секундах; при отсутствии параметра SHALL использоваться значение по умолчанию — 60 секунд. Значение `0` или отрицательное SHALL отключать ограничение по времени. Сценарий, превысивший таймаут, SHALL быть прерван с ошибкой, записанной в лог, а вызов, инициировавший выполнение, SHALL получить `null`.

#### Scenario: Таймаут не задан в конфигурации
- **WHEN** параметр `executionTimeout` отсутствует в конфигурации плагина
- **THEN** сценарий, выполняющийся дольше 60 секунд, прерывается с ошибкой

#### Scenario: Таймаут отключён
- **WHEN** параметр `executionTimeout` задан равным `0` или отрицательному значению
- **THEN** ограничение по времени выполнения сценария не применяется

#### Scenario: Сценарий превышает заданный таймаут
- **WHEN** выполнение сценария превышает заданный таймаут
- **THEN** выполнение прерывается, вызвавшему возвращается `null`, а ошибка записывается в лог

### Requirement: Логирование из сценария
Внутри сценария SHALL быть доступен объект `host.log` с методами `trace`, `debug`, `info`, `warn`, `error`, `fatal`, каждый из которых SHALL принимать первым параметром сообщение и произвольные дополнительные параметры для его форматирования и SHALL записывать сообщение в лог плагина `ScriptsPlugin` с соответствующим уровнем.

#### Scenario: Вызов host.log.info из сценария
- **WHEN** код сценария вызывает `host.log.info(сообщение, ...аргументы)`
- **THEN** сообщение с уровнем info записывается в лог плагина `ScriptsPlugin`

### Requirement: Вызов методов плагинов из сценария (ScriptCommand)
Метод плагина, помеченный атрибутом `ScriptCommandAttribute` с указанным именем (alias), SHALL быть доступен из кода сценария как `host.api.<alias>`; вызов из сценария SHALL передавать аргументы в метод и SHALL возвращать сценарию результат его работы. Обращение из сценария к имени, для которого нет зарегистрированного метода, SHALL приводить к ошибке, записанной в лог, без выполнения какого-либо метода.

#### Scenario: Вызов зарегистрированного метода плагина
- **WHEN** код сценария вызывает `host.api.<alias>(...)`, где `<alias>` зарегистрирован атрибутом `[ScriptCommand(alias)]` на методе плагина
- **THEN** метод плагина выполняется с переданными аргументами, а его результат возвращается сценарию

#### Scenario: Обращение к незарегистрированному имени метода
- **WHEN** код сценария обращается к `host.api.<alias>`, для которого нет зарегистрированного метода
- **THEN** возникает ошибка, записанная в лог, и метод не выполняется

### Requirement: Запуск других сценариев из сценария
Сохранённый сценарий SHALL быть доступен из кода другого сценария как `host.scripts.<name>` (или `host.scripts['<name>']` при имени, не являющемся валидным идентификатором JavaScript), где `<name>` — имя сохранённого сценария; вызов SHALL выполнять этот сценарий с переданными аргументами и SHALL возвращать его результат.

#### Scenario: Запуск сохранённого сценария по имени из другого сценария
- **WHEN** код сценария вызывает `host.scripts.<name>(...)`, где `<name>` — имя ранее сохранённого сценария
- **THEN** этот сохранённый сценарий выполняется с переданными аргументами, а его результат возвращается вызывающему сценарию

### Requirement: Работа с бинарными данными через Buffer
Класс `Buffer` SHALL оборачивать массив байтов так, чтобы при передаче в сценарий (в качестве аргумента или значения meta) тип данных не преобразовывался в массив чисел, как это происходит с обычным `byte[]`. Экземпляр `Buffer`, доступный в сценарии, SHALL предоставлять методы получения содержимого: как массива чисел, как строки в кодировке UTF-8 и как строки в кодировке Base64.

#### Scenario: Передача Buffer в сценарий как аргумента
- **WHEN** в сценарий передаётся аргумент типа `Buffer`, обёртывающий массив байтов
- **THEN** в сценарии этот аргумент остаётся объектом `Buffer` (не преобразуется в массив чисел) и его методы возвращают байты в виде массива чисел, UTF-8-строки и Base64-строки
