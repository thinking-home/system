## ADDED Requirements

### Requirement: Состояния списка расписания
Страница `/cron` SHALL отображать в области списка локализованное сообщение серым текстом с выравниванием по центру, когда список записей расписания пуст или его загрузка завершилась ошибкой. Пустое состояние SHALL показываться только после успешной загрузки пустого списка; при ошибке SHALL показываться состояние ошибки и уведомление об ошибке. Заголовок и действия страницы SHALL оставаться видимыми.

#### Scenario: Пустой список записей расписания
- **WHEN** запрос списка записей расписания успешно возвращает пустой список
- **THEN** в области списка отображается центрированное серое сообщение об отсутствии записей, а действие добавления записи остаётся доступно

#### Scenario: Ошибка загрузки списка расписания
- **WHEN** запрос списка записей расписания завершается ошибкой
- **THEN** в области списка отображается центрированное серое сообщение об ошибке и показывается уведомление об ошибке

### Requirement: Заголовок шторки записи расписания
Шторка добавления или редактирования записи расписания SHALL содержать ровно один семантический заголовок второго уровня для названия формы. Его размер шрифта, высота строки и насыщенность SHALL соответствовать оформлению заголовка второго уровня текущей темы Mantine и визуально выделять название относительно обычного текста шторки.

#### Scenario: Открытие шторки расписания с крупным заголовком
- **WHEN** пользователь открывает форму добавления или редактирования записи расписания
- **THEN** название формы отображается единственным заголовком второго уровня с оформлением `h2` текущей темы
