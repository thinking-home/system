## Purpose

Описывает демонстрационную страницу веб-интерфейса со списком данных, загружаемых через HTTP API плагина Tmp, и наблюдаемые состояния этой загрузки.

## ADDED Requirements

### Requirement: Демонстрационный список данных
Страница `/page2` SHALL загружать демонстрационный список через `/api/tmp/pigs` и SHALL отображать для каждого элемента его название и размер.

#### Scenario: Успешная загрузка демонстрационного списка
- **WHEN** запрос `/api/tmp/pigs` успешно возвращает непустой список
- **THEN** страница отображает название и размер каждого элемента списка

### Requirement: Состояния демонстрационного списка
Страница `/page2` SHALL отображать в области списка сообщение серым текстом с выравниванием по центру, если запрос успешно вернул пустой список, завершился ошибкой или был явно отменён пользователем. Пустое и ошибочное состояния SHALL быть различимы по тексту и SHALL заменять состояние загрузки после завершения или отмены запроса; явная отмена SHALL использовать оформление состояния ошибки с отдельным текстом об отмене.

#### Scenario: Пустой демонстрационный список
- **WHEN** запрос `/api/tmp/pigs` успешно возвращает пустой список
- **THEN** вместо состояния загрузки отображается центрированное серое сообщение об отсутствии данных

#### Scenario: Ошибка загрузки демонстрационного списка
- **WHEN** запрос `/api/tmp/pigs` завершается ошибкой
- **THEN** вместо состояния загрузки отображается центрированное серое сообщение об ошибке

#### Scenario: Отмена загрузки демонстрационного списка
- **WHEN** пользователь отменяет выполняющийся запрос `/api/tmp/pigs`
- **THEN** вместо состояния загрузки отображается центрированное серое сообщение «Загрузка отменена» в оформлении состояния ошибки
