# Совместная поставка

Проект ThinkingHome.Console упаковывается стандартным SDK как DotnetTool. Только Console зависит от System.CommandLine, описывает команды и аргументы th, обрабатывает консольные сигналы, сообщения и коды выхода. Библиотека Core.Infrastructure предоставляет PluginHost.Open, Start и Dispose; PackageManagement — API источников, планирования и установки без консольного ввода-вывода. Определение платформы входит в Packaging; Core.Plugins и Repository сохраняют отдельные проекты. Каждый вызов команды — новый процесс с одним и тем же графом зависимостей CLI и одним каталогом платформы для данной среды. Это исключает независимое обновление версий двух компонентов.

Инструмент содержит managed-сборки и файлы запуска CLI; пользовательская конфигурация и установленные плагины хранятся отдельно. Timer сохраняет формат пакета плагина. Конфигурация источника NuGet для установки самого tool и sources.json менеджера плагинов — разные входы.
