## MODIFIED Requirements

### Requirement: Загрузка конфигурации из файлов и переменных окружения
Система SHALL строить конфигурацию в порядке: сгенерированные настройки фактического плана (при наличии), необязательный `appsettings.json`, необязательный `appsettings.{ENV}.json` и переменные окружения с префиксом `THINKINGHOME_`. Более поздний источник SHALL переопределять значения более раннего. Файлы читаются из выбранного каталога приложения; ENV определяется переменной `THINKINGHOME_ENVIRONMENT`.

#### Scenario: файл переопределяет настройки плана
- **WHEN** значение задано в сгенерированной конфигурации и в пользовательском `appsettings.json`
- **THEN** используется значение из файла

#### Scenario: переменная окружения переопределяет значение из файла
- **WHEN** значение задано и в `appsettings.json`, и в переменной окружения `THINKINGHOME_<ключ>`
- **THEN** используется значение из переменной окружения

#### Scenario: окружение не задано
- **WHEN** переменная `THINKINGHOME_ENVIRONMENT` не установлена
- **THEN** файл окружения пропускается; сгенерированные настройки, основной файл и переменные окружения сохраняют свой приоритет
