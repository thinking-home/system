## ADDED Requirements

### Requirement: Установка хоста и менеджера одним инструментом
Пакет `ThinkingHome.Console` SHALL устанавливаться как один .NET tool с командой `th`. Хост и менеджер SHALL использовать платформу одной поставки, а плагины SHALL устанавливаться отдельно в каталог приложения.

#### Scenario: установка в чистом профиле
- **WHEN** на поддерживаемой x64-системе с .NET SDK 10 и ASP.NET Core 10 устанавливают точную версию CLI из NuGet с пустым кешем
- **THEN** доступны команды `run`, `install` и `uninstall`; для их работы не требуются исходники или отдельный менеджер

#### Scenario: установка и восстановление Timer
- **WHEN** пользователь устанавливает совместимый Timer через `th install` и выполняет `th ci` по его lock-файлу в другом каталоге
- **THEN** восстановленный архив соответствует хешу и версии из lock, а `run --app <каталог> --check` проверяет его без запуска жизненного цикла

#### Scenario: запуск вне каталога инструмента
- **WHEN** пользователь выполняет `th run` из восстановленного каталога без `--app`
- **THEN** хост читает установку и настройки из текущего рабочего каталога, запускает установленные плагины и штатно останавливается по сигналу консоли

#### Scenario: удаление установленного плагина
- **WHEN** пользователь выполняет `th uninstall <каталог> <id>` для независимо установленного Timer
- **THEN** плагин исчезает из активной установки; `th validate <каталог>` подтверждает её целостность

### Requirement: Граница командной строки
Только ThinkingHome.Console SHALL описывать команды th, разбирать их параметры и формировать консольные сообщения и коды выхода. Core.Infrastructure и PackageManagement SHALL предоставлять операции через API без зависимости от System.CommandLine.

#### Scenario: установка инструмента с разделёнными библиотеками
- **WHEN** проверяется граф зависимостей итогового tool
- **THEN** среди сборок ThinkingHome только Console зависит от System.CommandLine
