## Why

Потребителю нужен способ установить совместимые версии хоста и менеджера из NuGet на компьютер без исходников ThinkingHome.

## What Changes

- Один переносимый .NET tool `ThinkingHome.Console` предоставляет `th run` и `th install`.
- CLI и Timer собираются с общей версией `5.0.0-alpha.1`; Timer остаётся самостоятельно устанавливаемым плагином.
- Каталог приложения отделён от установки инструмента. Уточняется порядок конфигурации при запуске.

## Capabilities

### New Capabilities
- `core/cli-distribution`: установка одного инструмента, управление плагинами и запуск хоста.

### Modified Capabilities
- `core/application-bootstrap`: настройки из плана предшествуют пользовательским файлам и переменным окружения.

## Impact

Затронуты CLI, точки входа хоста и менеджера, общая версия, документация и приёмка. Docker и IDE запускают тот же Console; для явного запуска хоста используется подкоманда run. Отправка архивов в публичный каталог не входит в подготовку релиза.
