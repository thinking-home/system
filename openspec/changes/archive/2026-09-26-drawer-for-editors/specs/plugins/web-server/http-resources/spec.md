## MODIFIED Requirements

### Requirement: Динамический ресурс генерируется на каждый запрос
Зарегистрированный динамический ресурс SHALL при каждом запросе по своему URL вызывать обработчик, зарегистрированный для этого ресурса, передавая ему параметры запроса, и возвращать клиенту результат, сформированный обработчиком. Динамический ресурс SHALL опционально кэшироваться на сервере (по умолчанию не кэшируется); некэшируемый ответ SHALL сопровождаться заголовком `Cache-Control`, запрещающим кэширование. Закэшированный на сервере ответ SHALL отдаваться только на запрос с тем же путём и той же строкой запроса (query string); запрос того же ресурса с другой строкой запроса SHALL вызывать обработчик и получать ответ, сформированный для своих параметров.

#### Scenario: Запрос динамического ресурса вызывает обработчик
- **WHEN** выполняется запрос по URL, на котором зарегистрирован динамический ресурс
- **THEN** вызывается обработчик, зарегистрированный для этого URL, и клиенту возвращается результат, который он вернул

#### Scenario: Некэшируемый динамический ресурс
- **WHEN** динамический ресурс зарегистрирован без включённого кэширования
- **THEN** ответ на каждый запрос содержит заголовок `Cache-Control`, запрещающий кэширование

#### Scenario: Кэшируемый ресурс с разными параметрами строки запроса
- **GIVEN** динамический ресурс зарегистрирован с включённым кэшированием, и его ответ зависит от параметра строки запроса
- **WHEN** выполняется запрос с `?id=A`, затем запрос с `?id=B`
- **THEN** второй запрос получает ответ, сформированный обработчиком для `id=B`, а не закэшированный ответ для `id=A`

#### Scenario: Повторный запрос с той же строкой запроса
- **GIVEN** динамический ресурс зарегистрирован с включённым кэшированием
- **WHEN** дважды подряд выполняется запрос с одинаковыми путём и строкой запроса
- **THEN** обработчик вызывается один раз, а второй ответ отдаётся из кэша
