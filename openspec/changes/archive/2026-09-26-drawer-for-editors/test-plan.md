## Ручные проверки

Окружение: `dotnet run` из `ThinkingHome.Console` (порт 8090, см. `local-run-environment`), после сборки `dotnet build ThinkingHome.sln` дважды (`th-build` компилируется вторым проходом). Проверять через `sbox-browser` или обычный браузер.

### plugins/cron/web-ui › Форма записи расписания в шторке › Открытие формы новой записи

- Шаги: открыть `/cron`; нажать кнопку добавления новой записи.
- Ожидаемый результат: справа открывается шторка (Drawer) с пустой формой записи; список записей остаётся видимым на странице.
- Окружение: локальный запуск, раздел `/cron`.

### plugins/cron/web-ui › Форма записи расписания в шторке › Открытие формы редактирования

- Шаги: на `/cron` кликнуть по названию существующей записи.
- Ожидаемый результат: открывается шторка с формой, заполненной данными этой записи.

### plugins/cron/web-ui › Форма записи расписания в шторке › Успешное сохранение закрывает шторку

- Шаги: открыть шторку, корректно заполнить форму, сохранить.
- Ожидаемый результат: шторка закрывается, список показывает сохранённую запись.

### plugins/cron/web-ui › Форма записи расписания в шторке › Ошибка сохранения оставляет шторку открытой

- Шаги: открыть шторку, заполнить форму так, чтобы сохранение завершилось ошибкой сервера (например, дублирующееся или некорректное значение, если API его отклоняет).
- Ожидаемый результат: шторка остаётся открытой, введённые данные не сбрасываются, показывается уведомление об ошибке.

### plugins/cron/web-ui › Форма записи расписания в шторке › Закрытие шторки без сохранения

- Шаги: открыть форму новой записи, ввести данные, закрыть шторку (кнопкой отмены, кнопкой закрытия, Escape или кликом вне шторки) без сохранения; снова открыть форму новой записи.
- Ожидаемый результат: форма пуста, новой записи в списке нет.

### plugins/scripts/web-ui › Форма подписки в шторке › Открытие формы новой подписки

- Шаги: открыть `/scripts/subscriptions`; нажать кнопку добавления новой подписки.
- Ожидаемый результат: справа открывается шторка с пустой формой подписки; список подписок остаётся видимым на странице.

### plugins/scripts/web-ui › Форма подписки в шторке › Успешное добавление закрывает шторку

- Шаги: в шторке выбрать сценарий и событие, добавить подписку.
- Ожидаемый результат: шторка закрывается, новая подписка появляется в списке.

### plugins/scripts/web-ui › Форма подписки в шторке › Ошибка добавления оставляет шторку открытой

- Шаги: в шторке заполнить форму подписки так, чтобы добавление завершилось ошибкой сервера.
- Ожидаемый результат: шторка остаётся открытой, введённые данные сохраняются, показывается уведомление об ошибке.

### plugins/scripts/web-ui › Форма подписки в шторке › Закрытие шторки подписки без сохранения

- Шаги: в шторке выбрать сценарий и событие, закрыть шторку без сохранения; снова открыть форму.
- Ожидаемый результат: форма пуста, подписка не создана.
