## Зачем

Данные о чатах Telegram уже накапливаются и доступны по HTTP API, но у пользователя нет способа их посмотреть: чтобы узнать идентификатор чата для настройки уведомлений, приходится обращаться к API или к базе вручную. Веб-интерфейс системы уже даёт разделы для расписания и сценариев, поэтому список чатов логично показать тем же способом.

## Границы изменения

### Входит

- Новый раздел веб-интерфейса со списком всех сохранённых чатов Telegram.
- Отображение всех полей записи чата, которые отдаёт существующее HTTP API.
- Локализация подписей раздела (по умолчанию английский, перевод на русский) — как в остальных разделах.
- Переход в раздел с корневой страницы веб-интерфейса.
- Включение нового раздела в поставку: он загружается в стандартной конфигурации приложения.

### Не входит

- Пагинация, сортировка, поиск и фильтры списка.
- Создание, редактирование и удаление записей чатов.
- Изменение HTTP API списка чатов и состава его полей.
- Изменение правил накопления чатов и логики телеграм-бота.
- Переработка корневой страницы веб-интерфейса (добавляется только пункт со ссылкой).
- Обновления списка в реальном времени через шину сообщений.

## Функциональности

### Новые

- `plugins/telegram-chat-list/web-ui`: раздел веб-интерфейса, который загружает список чатов через HTTP API плагина и показывает все поля записи в таблице; при пустом списке отображает соответствующее сообщение; доступен по ссылке с корневой страницы.

### Изменяемые

— (существующие capability не меняются: `plugins/telegram-chat-list/http-api` используется как есть, `plugins/web-ui/page-registration` и `plugins/web-ui/application-shell` задают уже действующий контракт регистрации и оболочки)

## Внешнее влияние

- Потребитель — пользователь веб-интерфейса: появляется новый пункт на корневой странице и новый маршрут раздела.
- Зависимость нового раздела: существующий эндпоинт списка чатов; состав его полей становится контрактом отображения, но сам эндпоинт не меняется.
- Состав поставки: в стандартную конфигурацию приложения добавляется ещё одна загружаемая сборка плагина; при отсутствии плагина HTTP API раздел данных не получит.
- Несовместимых изменений нет.
