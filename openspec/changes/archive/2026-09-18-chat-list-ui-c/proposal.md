## Зачем

Список чатов Telegram сегодня доступен только как HTTP API: посмотреть, какие чаты зарегистрированы, из веб-интерфейса нельзя, приходится обращаться к эндпоинту вручную. Нужен отдельный раздел веб-интерфейса, который показывает эти данные человеку, и предсказуемый порядок записей — самые свежие чаты сверху.

## Границы изменения

### Входит

- Новый раздел веб-интерфейса со списком сохранённых чатов Telegram; отображаются все поля записи о чате.
- Переход в раздел с корневой страницы веб-интерфейса.
- Фиксированный на сервере порядок записей в ответе HTTP API: по дате по убыванию.
- Подключение нового раздела к сборке и конфигурации приложения, локализация раздела.

### Не входит

- Пагинация, фильтры, поиск и сортировка, управляемая пользователем.
- Изменение состава полей ответа HTTP API и модели хранения чатов.
- Редактирование, удаление чатов и любые другие действия над записями: раздел только для чтения.
- Изменение контрактов регистрации разделов и оболочки веб-интерфейса.

## Функциональности

### Новые

- `plugins/telegram-chat-list/web-ui`: раздел веб-интерфейса со списком сохранённых чатов Telegram, использующий HTTP API списка чатов.

### Изменяемые

- `plugins/telegram-chat-list/http-api`: список чатов возвращается в фиксированном порядке — по дате по убыванию.
- `plugins/web-ui/application-shell`: с корневой страницы доступен переход в новый раздел (уточнение способа фиксации — вопрос фазы планирования).

## Внешнее влияние

- Потребители HTTP API списка чатов получают тот же состав полей, но гарантированный порядок записей; несовместимых изменений нет.
- Новый раздел зависит от существующих контрактов регистрации разделов и оболочки веб-интерфейса, сами контракты не меняются.
- Требуется подключение нового плагина в конфигурации приложения: без записи в списке подключаемых сборок раздел не появится.
