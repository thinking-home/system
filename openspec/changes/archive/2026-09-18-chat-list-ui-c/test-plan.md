## Ручные проверки

Окружение для всех проверок: локальный PostgreSQL (контейнер `postgres`, пароль `123` по `README.md`),
`appsettings.Development.json` в `ThinkingHome.Console` с подключёнными плагинами
`TelegramChatList`, `TelegramChatList.WebApi`, `TelegramChatList.WebUi`, `WebUi`, запуск
`cd ThinkingHome.Console && dotnet run`, веб-интерфейс на порту из конфигурации (`8080` по умолчанию).

### `plugins/telegram-chat-list/http-api` › Список сохранённых чатов › Запрос списка чатов

- Шаги: добавить в таблицу `TelegramChatList_Chat` несколько записей (через сценарий Telegram-бота или напрямую в БД), выполнить `GET /api/telegram-chat-list/web-api/list`.
- Ожидаемый результат: в ответе — все сохранённые записи, каждая с полями `id`, `login`, `chatId`, `firstName`, `lastName`, `date`.

### `plugins/telegram-chat-list/http-api` › Список сохранённых чатов › Отсутствующие значения полей

- Шаги: создать запись о чате без `Login`, `FirstName` или `LastName`, выполнить запрос списка.
- Ожидаемый результат: соответствующие поля (`login`, `firstName`, `lastName`) в ответе — `null`.

### `plugins/telegram-chat-list/http-api` › Список сохранённых чатов › Порядок записей в ответе

- Шаги: создать записи с разными значениями `Date`, выполнить запрос списка несколько раз.
- Ожидаемый результат: записи всегда идут по убыванию `date` (самая поздняя — первая), порядок не зависит от параметров запроса.

### `plugins/telegram-chat-list/web-ui` › Зависимость от HTTP API списка чатов › Раздел использует HTTP API списка чатов

- Шаги: открыть `/telegram-chat-list` в браузере с открытой вкладкой «Сеть» инструментов разработчика.
- Ожидаемый результат: страница выполняет запрос `GET /api/telegram-chat-list/web-api/list`, данные для таблицы приходят из этого ответа.

### `plugins/telegram-chat-list/web-ui` › Раздел списка чатов › Открытие списка чатов

- Шаги: открыть `/telegram-chat-list` при наличии сохранённых чатов.
- Ожидаемый результат: отображается таблица, у каждой строки заполнены столбцы `id`, `chatId`, `login`, `firstName`, `lastName`, `date`.

### `plugins/telegram-chat-list/web-ui` › Раздел списка чатов › Порядок записей в таблице

- Шаги: сверить порядок строк таблицы с порядком записей в ответе `GET /api/telegram-chat-list/web-api/list` (та же вкладка «Сеть»).
- Ожидаемый результат: порядок строк совпадает с порядком в ответе API, без собственной пересортировки на клиенте.

### `plugins/telegram-chat-list/web-ui` › Раздел списка чатов › Раздел не содержит действий изменения

- Шаги: осмотреть страницу `/telegram-chat-list` целиком.
- Ожидаемый результат: нет кнопок и элементов создания, редактирования или удаления записей.

### `plugins/telegram-chat-list/web-ui` › Отображение незаданных значений и пустого списка › Запись с незаданными полями

- Шаги: открыть `/telegram-chat-list`, когда среди чатов есть запись с `login`, `firstName` или `lastName`, равными `null`.
- Ожидаемый результат: в соответствующих ячейках таблицы — прочерк, а не пустая ячейка.

### `plugins/telegram-chat-list/web-ui` › Отображение незаданных значений и пустого списка › Пустой список чатов

- Шаги: очистить таблицу `TelegramChatList_Chat` (или проверить на чистой БД), открыть `/telegram-chat-list`.
- Ожидаемый результат: вместо таблицы — сообщение об отсутствии сохранённых чатов.

### `plugins/telegram-chat-list/web-ui` › Ошибка загрузки списка чатов › Запрос списка завершился ошибкой

- Шаги: сделать запрос `/api/telegram-chat-list/web-api/list` неуспешным (например, временно остановить PostgreSQL или подменить ответ через инструменты разработчика), открыть `/telegram-chat-list`.
- Ожидаемый результат: показывается уведомление об ошибке загрузки данных, таблица чатов не отображается (в том числе частично).

### `plugins/web-ui/application-shell` › Ссылка на раздел списка чатов на корневой странице › Переход в раздел списка чатов с корневой страницы

- Шаги: открыть корневую страницу веб-интерфейса, найти ссылку на раздел списка чатов и перейти по ней.
- Ожидаемый результат: открывается раздел `/telegram-chat-list` со списком чатов.
