## Ручные проверки

Среда: локальный PostgreSQL (контейнер `postgres`, пароль `123`), `appsettings.Development.json` в `ThinkingHome.Console`, `cd ThinkingHome.Console && dotnet run`, веб-интерфейс на порту из `appsettings.json` (по умолчанию 8080; в этом окружении занят — использовать 8090 через переменную окружения). Плагины `TelegramChatList.WebApi` и `TelegramChatList.WebUi` подключены вместе в `assemblies`.

### Раздел использует HTTP API списка чатов
- Шаги: открыть `/telegram-chat-list`; открыть вкладку «Сеть» в инструментах разработчика браузера.
- Ожидаемый результат: страница выполняет запрос `GET /api/telegram-chat-list/web-api/list`; прямых обращений к БД или другому эндпоинту для получения списка нет.

### Открытие списка чатов
- Шаги: в БД должно быть несколько записей о чатах (сохранённых плагином `TelegramChatList` через реальную переписку с ботом либо вставленных вручную в таблицу). Открыть `/telegram-chat-list`.
- Ожидаемый результат: отображается таблица со всеми сохранёнными записями; в каждой строке видны значения `id`, `login`, `chatId`, `firstName`, `lastName`, `date`.

### Запись с незаполненными полями
- Шаги: убедиться, что среди записей есть запись с `login`, `firstName` или `lastName`, равными `null` (например, чат без имени пользователя в Telegram). Открыть `/telegram-chat-list`.
- Ожидаемый результат: строка записи отображается, незаполненные поля показаны пустыми, без ошибок в консоли браузера.

### Список чатов пуст
- Шаги: очистить таблицу чатов в БД (или использовать окружение без сохранённых чатов). Открыть `/telegram-chat-list`.
- Ожидаемый результат: вместо таблицы показано сообщение об отсутствии записей.

### Ошибка загрузки списка
- Шаги: временно отключить или сломать эндпоинт `/api/telegram-chat-list/web-api/list` (например, остановить БД или отключить плагин `TelegramChatList.WebApi`, оставив `TelegramChatList.WebUi`). Открыть `/telegram-chat-list`.
- Ожидаемый результат: пользователю показано уведомление об ошибке загрузки данных; таблица не отображается.

### Отображение раздела на русском языке
- Шаги: переключить язык интерфейса на русский. Открыть `/telegram-chat-list`.
- Ожидаемый результат: заголовок раздела, заголовки колонок и сообщение о пустом списке (если список пуст) отображаются на русском языке.

### Переход на список чатов с корневой страницы
- Шаги: открыть корневую страницу веб-интерфейса, найти ссылку на список чатов Telegram, перейти по ней.
- Ожидаемый результат: открывается раздел `/telegram-chat-list`.
