## Purpose

Добавляет в веб-интерфейс раздел для просмотра списка чатов Telegram, сохранённых плагином `TelegramChatList`, использующий HTTP API `plugins/telegram-chat-list/http-api`.

## ADDED Requirements

### Requirement: Зависимость от HTTP API списка чатов
`TelegramChatList.WebUi` SHALL получать все данные о чатах через HTTP API `plugins/telegram-chat-list/http-api`; для корректной работы раздела `TelegramChatList.WebUi` SHALL быть подключён вместе с плагином, предоставляющим этот API. Раздел SHALL не обращаться к базе данных и не хранить собственную копию списка чатов.

#### Scenario: Раздел использует HTTP API списка чатов
- **WHEN** пользователь открывает раздел `TelegramChatList.WebUi`
- **THEN** данные для раздела запрашиваются через HTTP API `/api/telegram-chat-list/web-api/list`

### Requirement: Раздел списка чатов
Страница `/telegram-chat-list` SHALL отображать таблицу всех сохранённых записей о чатах, полученных от HTTP API, без пагинации, сортировки и фильтров. Для каждой записи SHALL отображаться значения всех полей ответа API: `id`, `login`, `chatId`, `firstName`, `lastName`, `date`. Раздел SHALL не предоставлять действий изменения или удаления записей.

#### Scenario: Открытие списка чатов
- **WHEN** пользователь открывает `/telegram-chat-list`
- **THEN** отображается таблица всех сохранённых чатов, в каждой строке показаны поля `id`, `login`, `chatId`, `firstName`, `lastName` и `date`

#### Scenario: Запись с незаполненными полями
- **WHEN** в списке есть запись, у которой `login`, `firstName` или `lastName` равны `null`
- **THEN** строка записи отображается, а незаполненные поля показаны как пустые значения

### Requirement: Пустой список и ошибка загрузки
Если HTTP API вернул пустой список чатов, раздел SHALL отображать сообщение об отсутствии записей вместо таблицы. Если запрос списка завершился ошибкой, раздел SHALL показать пользователю уведомление об ошибке загрузки данных.

#### Scenario: Список чатов пуст
- **WHEN** пользователь открывает `/telegram-chat-list` и сохранённых чатов нет
- **THEN** вместо таблицы отображается сообщение об отсутствии записей

#### Scenario: Ошибка загрузки списка
- **WHEN** запрос списка чатов завершается ошибкой
- **THEN** пользователю отображается уведомление об ошибке загрузки данных

### Requirement: Локализация подписей раздела
Подписи раздела (заголовок, заголовки колонок, сообщение о пустом списке, текст ошибки загрузки) SHALL задаваться по умолчанию на английском языке и SHALL переводиться на русский язык через ресурсы локализации плагина.

#### Scenario: Отображение раздела на русском языке
- **WHEN** пользователь открывает раздел при выбранном русском языке интерфейса
- **THEN** заголовок раздела, заголовки колонок и сообщение о пустом списке отображаются на русском языке

### Requirement: Переход в раздел с корневой страницы
Корневая страница веб-интерфейса SHALL содержать ссылку на раздел списка чатов Telegram.

#### Scenario: Переход на список чатов с корневой страницы
- **WHEN** пользователь открывает корневую страницу веб-интерфейса и переходит по ссылке на список чатов Telegram
- **THEN** открывается раздел `/telegram-chat-list`
