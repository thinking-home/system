## ADDED Requirements

### Requirement: Ссылка на раздел списка чатов на корневой странице
Корневая страница приложения SHALL содержать ссылку на раздел списка чатов Telegram (`plugins/telegram-chat-list/web-ui`), переход по которой открывает этот раздел.

#### Scenario: Переход в раздел списка чатов с корневой страницы
- **WHEN** пользователь открывает корневую страницу и переходит по ссылке на раздел списка чатов
- **THEN** отображается раздел списка чатов Telegram
