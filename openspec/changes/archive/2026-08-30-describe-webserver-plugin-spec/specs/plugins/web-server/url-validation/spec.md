## Purpose

Проверяет, что HTTP-ресурсы, зарегистрированные плагинами через веб-сервер, соответствуют правилам формирования URL, и публикует список найденных несоответствий.

## ADDED Requirements

### Requirement: Вычисление alias плагина
Alias плагина, зарегистрировавшего HTTP-ресурс, SHALL вычисляться из имени сборки, в которой определён тип-источник ресурса: из имени сборки SHALL быть убран префикс `ThinkingHome.Plugins.`, если он есть; границы между частями имени в camelCase SHALL быть заменены дефисом (`-`); точки SHALL быть заменены на слэш (`/`); результат SHALL быть приведён к нижнему регистру.

#### Scenario: Alias простого плагина
- **WHEN** ресурс зарегистрирован типом из сборки `ThinkingHome.Plugins.MyPlugin`
- **THEN** его alias вычисляется как `my-plugin`

#### Scenario: Alias плагина с составным именем и вложенным пакетом
- **WHEN** ресурс зарегистрирован типом из сборки `ThinkingHome.Plugins.MyPlugin.InnerPackage`
- **THEN** его alias вычисляется как `my-plugin/inner-package`

### Requirement: Проверка URL динамических ресурсов
URL динамического ресурса с префиксом `/api/{alias}/` (где `alias` — alias плагина, зарегистрировавшего ресурс) SHALL не иметь расширения файла; нарушение SHALL быть зафиксировано как ошибка. URL с префиксом `/dynamic/{alias}/` SHALL иметь непустое расширение файла; нарушение SHALL быть зафиксировано как ошибка. URL динамического ресурса, не начинающийся ни с `/api/{alias}/`, ни с `/dynamic/{alias}/`, SHALL быть зафиксирован как ошибка недопустимого префикса.

#### Scenario: URL /api/ с расширением
- **WHEN** динамический ресурс плагина с alias `my-plugin` зарегистрирован по URL `/api/my-plugin/add.json`
- **THEN** проверка фиксирует ошибку о непустом расширении у API-адреса

#### Scenario: URL /dynamic/ без расширения
- **WHEN** динамический ресурс плагина с alias `my-plugin` зарегистрирован по URL `/dynamic/my-plugin/report`
- **THEN** проверка фиксирует ошибку о пустом расширении у dynamic-адреса

#### Scenario: URL динамического ресурса без ожидаемого префикса
- **WHEN** динамический ресурс плагина с alias `my-plugin` зарегистрирован по URL `/other/my-plugin/x`
- **THEN** проверка фиксирует ошибку недопустимого префикса

### Requirement: Проверка URL статических ресурсов
URL статических ресурсов `/` и `/favicon.ico` SHALL быть исключены из проверки. Любой другой URL статического ресурса SHALL иметь непустое расширение файла; нарушение SHALL быть зафиксировано как ошибка. Такой URL SHALL начинаться либо с `/vendor/`, либо с `/static/{alias}/` (где `alias` — alias плагина, зарегистрировавшего ресурс); нарушение SHALL быть зафиксировано как ошибка недопустимого префикса.

#### Scenario: Исключённые адреса не проверяются
- **WHEN** статический ресурс зарегистрирован по URL `/` или `/favicon.ico`
- **THEN** проверка не фиксирует для него ошибок независимо от расширения и префикса

#### Scenario: Статический ресурс без расширения
- **WHEN** статический ресурс плагина с alias `my-plugin` зарегистрирован по URL `/static/my-plugin/readme`
- **THEN** проверка фиксирует ошибку о пустом расширении

#### Scenario: Статический ресурс с недопустимым префиксом
- **WHEN** статический ресурс плагина с alias `my-plugin` зарегистрирован по URL `/other/my-plugin/app.js`
- **THEN** проверка фиксирует ошибку недопустимого префикса

#### Scenario: Статический ресурс из библиотеки стороннего разработчика
- **WHEN** статический ресурс зарегистрирован по URL, начинающемуся с `/vendor/` (например, `/vendor/js/lib.js`)
- **THEN** проверка не фиксирует ошибку недопустимого префикса для этого URL, независимо от alias плагина, его зарегистрировавшего

### Requirement: Публикация списка найденных ошибок
Список ошибок, накопленных при проверке всех HTTP-ресурсов, зарегистрированных к моменту инициализации, SHALL быть доступен по HTTP-адресу `/dynamic/web-server/url-validation/errors.txt` в виде текста, где каждая ошибка выводится на отдельной строке в формате `[<тип плагина>] :: <сообщение>`.

#### Scenario: Запрос списка ошибок
- **WHEN** выполняется GET-запрос по адресу `/dynamic/web-server/url-validation/errors.txt`
- **THEN** ответ содержит текстовый список найденных ошибок, по одной на строку, каждая в формате `[<тип плагина>] :: <сообщение>`

#### Scenario: Ошибок не найдено
- **WHEN** ни у одного зарегистрированного ресурса не найдено нарушений
- **THEN** ответ по адресу `/dynamic/web-server/url-validation/errors.txt` не содержит строк с ошибками
