## Purpose

Описывает API, который `DatabasePlugin` предоставляет другим плагинам для описания своей модели данных и для чтения/записи данных через Entity Framework Core.

## ADDED Requirements

### Requirement: Регистрация модели данных плагина
Плагин SHALL собирать модель данных для EF Core из методов всех загруженных плагинов, отмеченных атрибутом `DbModelBuilder` и соответствующих по сигнатуре делегату `DbModelBuilderDelegate`; эти методы SHALL вызываться при построении модели БД (`OnModelCreating`) в порядке, в котором они были обнаружены при инициализации.

#### Scenario: плагин регистрирует свою модель
- **WHEN** плагин отмечает метод атрибутом `DbModelBuilder`
- **THEN** этот метод вызывается при построении модели `DbContext`, полученного через `OpenSession`, и может настроить маппинг своих сущностей через `ModelBuilder`

#### Scenario: у плагина нет методов с атрибутом
- **WHEN** ни один метод плагина не отмечен атрибутом `DbModelBuilder`
- **THEN** модель БД строится без вклада этого плагина, ошибки не возникает

### Requirement: Открытие сессии для доступа к данным
Плагин SHALL предоставлять метод `OpenSession()`, возвращающий новый экземпляр `DbContext`, в модели которого учтены все методы, зарегистрированные через атрибут `DbModelBuilder` на момент инициализации `DatabasePlugin`.

#### Scenario: получение DbContext
- **WHEN** любой плагин вызывает `OpenSession()`
- **THEN** возвращается новый `DbContext`, готовый к чтению и записи сущностей, зарегистрированных через `DbModelBuilder`

### Requirement: API не зависит от конкретной СУБД
Контракт, который плагин предоставляет другим плагинам (`[DbModelBuilder]`, `DbModelBuilderDelegate`, `OpenSession`), SHALL быть выражен в терминах EF Core (`ModelBuilder`, `DbContext`) и SHALL не требовать от плагинов-потребителей знания о конкретной используемой СУБД. Плагины-потребители не SHALL полагаться на специфичные для PostgreSQL возможности при использовании этого API.

#### Scenario: плагин настраивает модель без привязки к СУБД
- **WHEN** плагин настраивает маппинг своих сущностей через `ModelBuilder` в методе с атрибутом `DbModelBuilder`
- **THEN** для этого используются только средства EF Core, общие для поддерживаемых провайдеров, без обращения к специфике PostgreSQL
