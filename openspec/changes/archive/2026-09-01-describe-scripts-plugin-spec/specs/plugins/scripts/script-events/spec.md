## Purpose

Позволяет плагинам регистрировать собственные сценарные события и инициировать их, автоматически выполняя все сценарии, подписанные на событие, с фильтрацией подписок по значениям meta события.

## ADDED Requirements

### Requirement: Регистрация событий плагина через атрибут
Метод плагина, помеченный атрибутом `ConfigureScriptEventsAttribute` и соответствующий по сигнатуре делегату `ConfigureScriptEventsDelegate` (один параметр — `ScriptEventsConfigurationBuilder`, без возвращаемого значения), SHALL быть вызван при инициализации плагина `ScriptsPlugin` с билдером, через который плагин регистрирует свои сценарные события. Если плагин `ScriptsPlugin` не подключён к системе, регистрация SHALL не происходить, а поля с emitter'ами SHALL оставаться `null`.

#### Scenario: Метод с атрибутом ConfigureScriptEvents вызывается при инициализации
- **WHEN** плагин объявляет метод с атрибутом `[ConfigureScriptEvents]`, соответствующий `ConfigureScriptEventsDelegate`
- **THEN** при инициализации `ScriptsPlugin` этот метод вызывается один раз с билдером, через который плагин может зарегистрировать свои события

#### Scenario: Плагин Scripts не подключён к системе
- **WHEN** плагин, поле которого получает emitter из `RegisterEvent`, работает в системе без подключённого `ScriptsPlugin`
- **THEN** поле с emitter'ом остаётся `null`

### Requirement: Регистрация события с параметрами и без
Билдер SHALL предоставлять метод `RegisterEvent(string name)` для регистрации события без параметров и метод `RegisterEvent<TArgs>(string name)` для регистрации события, в обработчики которого передаются параметры типа `TArgs`. Оба метода SHALL возвращать emitter — функцию, вызов которой инициирует зарегистрированное событие; вызывать emitter допустимо только после завершения фазы инициализации плагинов. Имя события SHALL быть непустой строкой; попытка зарегистрировать событие с пустым или отсутствующим именем SHALL приводить к ошибке.

#### Scenario: Регистрация события без параметров
- **WHEN** плагин вызывает `RegisterEvent(name)` с непустым именем
- **THEN** событие регистрируется под этим именем и возвращается emitter для его инициации без параметров

#### Scenario: Регистрация события с типизированными параметрами
- **WHEN** плагин вызывает `RegisterEvent<TArgs>(name)` с непустым именем
- **THEN** событие регистрируется под этим именем с типом параметров `TArgs`, и возвращается emitter, принимающий параметры этого типа

#### Scenario: Регистрация события с пустым именем
- **WHEN** плагин вызывает `RegisterEvent`/`RegisterEvent<TArgs>` с пустым именем (или `null`)
- **THEN** регистрация завершается ошибкой

### Requirement: Уникальность имён событий
Название сценарного события SHALL быть уникально в масштабе системы без учёта регистра. Повторная регистрация уже занятого имени SHALL приводить к ошибке при старте приложения.

#### Scenario: Повторная регистрация имени события
- **WHEN** два плагина регистрируют событие с одним и тем же именем (без учёта регистра)
- **THEN** регистрация завершается ошибкой при старте приложения

### Requirement: Инициация события вызывает подписанные сценарии
Вызов emitter'а зарегистрированного события SHALL асинхронно выполнить все сценарии, подписки которых соответствуют этому событию (см. фильтрацию по meta), передав каждому обработчику параметры события как `args` и словарь meta как `meta`. Ошибка выполнения одного обработчика SHALL не прерывать выполнение остальных подписанных обработчиков.

#### Scenario: Инициация события с подписанными сценариями
- **WHEN** вызывается emitter события, на которое подписан один или несколько сценариев (с подходящим по фильтру meta)
- **THEN** каждый подписанный сценарий асинхронно выполняется с параметрами события в `args` и словарём meta в `meta`

#### Scenario: Ошибка одного обработчика не блокирует остальные
- **WHEN** среди сценариев, подписанных на инициированное событие, один завершается ошибкой
- **THEN** остальные подписанные сценарии всё равно выполняются

### Requirement: Пользовательское событие
Плагин `ScriptsPlugin` SHALL регистрировать особое сценарное событие с именем `scripts:user-event` (константа `ScriptsPlugin.UserEventName`), предназначенное для сценариев с произвольными (динамическими) именами. Метод `EmitUserEvent(string name, params object[] args)` SHALL инициировать это событие, помещая переданное имя в словарь meta под ключом `name` (константа `ScriptsPlugin.UserEventNameMetaKey`) и передавая `args` как параметры события. Имя пользовательского события SHALL быть непустой строкой; пустое или отсутствующее имя SHALL приводить к ошибке. Перегрузка `EmitUserEvent(string name, IReadOnlyDictionary<string, string> meta, params object[] args)` SHALL дополнительно добавлять переданные пары meta к событию, но значение с ключом `name` SHALL всегда быть перезаписано именем события.

#### Scenario: Инициация пользовательского события
- **WHEN** вызывается `EmitUserEvent(name, args)`
- **THEN** инициируется событие `scripts:user-event` с meta, содержащей `name` = переданное имя, и параметрами `args`

#### Scenario: Пользовательское событие с дополнительным meta
- **WHEN** вызывается `EmitUserEvent(name, meta, args)` с дополнительным словарём meta, содержащим ключ, отличный от `name`
- **THEN** инициированное событие содержит переданные пары meta вместе с `name` = переданное имя

#### Scenario: Дополнительный meta переопределяет name
- **WHEN** вызывается `EmitUserEvent(name, meta, args)`, и переданный `meta` содержит собственное значение по ключу `name`
- **THEN** в meta инициированного события ключ `name` содержит имя события, переданное первым параметром, а не значение из `meta`

#### Scenario: Пустое имя пользовательского события
- **WHEN** вызывается `EmitUserEvent` с пустым или отсутствующим именем
- **THEN** вызов завершается ошибкой

### Requirement: Подписка сценария на событие
Подписка сценария на сценарное событие SHALL представляться записью `ScriptEventHandler` с полями `Id` (идентификатор подписки), `EventName` (имя события), `MetaFilter` (фильтр по meta события) и ссылкой на подписанный `UserScript`.

#### Scenario: Хранение подписки
- **WHEN** сценарий подписывается на сценарное событие
- **THEN** подписка представлена записью `ScriptEventHandler` с идентификатором, именем события, фильтром meta и ссылкой на сценарий

### Requirement: Фильтрация подписки по meta
Подписка SHALL опционально задавать фильтр — набор пар «ключ-значение», хранимый как строка в формате query string (пары разделены `&`, ключ и значение — `=`, оба URL-кодированы). Подписка с пустым фильтром (`null` или пустая строка) SHALL срабатывать на любое событие с указанным именем. Подписка с непустым фильтром SHALL срабатывать только если для каждой пары фильтра meta события содержит ключ с точно таким же (с учётом регистра) значением; при отсутствии в meta события какого-либо ключа фильтра, или отсутствии meta вовсе, подписка SHALL не срабатывать.

#### Scenario: Подписка без фильтра
- **WHEN** инициировано событие с именем, на которое подписан сценарий с пустым фильтром
- **THEN** подписанный сценарий выполняется независимо от содержимого meta события

#### Scenario: Подписка с фильтром, meta события совпадает
- **WHEN** инициировано событие, чьё meta содержит все пары ключ-значение, заданные в фильтре подписки
- **THEN** подписанный сценарий выполняется

#### Scenario: Подписка с фильтром, meta события не совпадает
- **WHEN** инициировано событие, чьё meta не содержит хотя бы одну из пар ключ-значение фильтра подписки (или не содержит соответствующий ключ вовсе)
- **THEN** подписанный сценарий не выполняется

### Requirement: Список зарегистрированных событий
Метод `GetRegisteredEvents()` SHALL возвращать список всех зарегистрированных сценарных событий — их имена, тип плагина-владельца и тип параметров (`null` для события без параметров), — упорядоченный по имени.

#### Scenario: Получение списка зарегистрированных событий
- **WHEN** вызывается `GetRegisteredEvents()`
- **THEN** возвращается список зарегистрированных событий с именем, плагином-владельцем и типом параметров, упорядоченный по имени
