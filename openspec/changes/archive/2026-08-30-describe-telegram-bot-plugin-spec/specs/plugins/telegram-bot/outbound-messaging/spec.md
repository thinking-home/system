## Purpose

Отправка ботом текстовых сообщений, изображений и файлов в чаты Telegram по запросу других плагинов и сценариев.

## ADDED Requirements

### Requirement: Отправка текстового сообщения
Плагин SHALL предоставлять возможность отправить текстовое сообщение в чат по его идентификатору.

#### Scenario: Успешная отправка текста
- **WHEN** вызывается отправка сообщения с идентификатором чата и текстом
- **THEN** боту Telegram отправляется запрос на отправку этого текста в указанный чат

### Requirement: Отправка изображения
Плагин SHALL предоставлять возможность отправить изображение в чат по его идентификатору, передав изображение содержимым потока с указанием имени файла или указав изображение ссылкой на URL.

#### Scenario: Отправка изображения из потока
- **WHEN** вызывается отправка изображения с идентификатором чата, именем файла и потоком с содержимым
- **THEN** боту Telegram отправляется запрос на отправку этого изображения в указанный чат

#### Scenario: Отправка изображения по URL
- **WHEN** вызывается отправка изображения с идентификатором чата и URL изображения
- **THEN** боту Telegram отправляется запрос на отправку изображения по этому URL в указанный чат

### Requirement: Отправка файла
Плагин SHALL предоставлять возможность отправить произвольный файл в чат по его идентификатору, передав файл содержимым потока с указанием имени файла или указав файл ссылкой на URL.

#### Scenario: Отправка файла из потока
- **WHEN** вызывается отправка файла с идентификатором чата, именем файла и потоком с содержимым
- **THEN** боту Telegram отправляется запрос на отправку этого файла в указанный чат

#### Scenario: Отправка файла по URL
- **WHEN** вызывается отправка файла с идентификатором чата и URL файла
- **THEN** боту Telegram отправляется запрос на отправку файла по этому URL в указанный чат

### Requirement: Изоляция ошибок отправки
Ошибка при отправке сообщения, изображения или файла SHALL логироваться. Отправка SHALL NOT прерывать работу вызывающего кода исключением при такой ошибке.

#### Scenario: Ошибка отправки не приводит к исключению у вызывающей стороны
- **WHEN** запрос на отправку сообщения, изображения или файла завершается ошибкой
- **THEN** ошибка логируется, а вызвавший отправку код не получает исключение
