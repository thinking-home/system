# Результат — planner / propose (r2)

## Сводка

- Записан `openspec/changes/chat-list-ui/proposal.md`: раздел веб-интерфейса со списком сохранённых чатов Telegram (все поля записи), данные — через существующий HTTP API списка чатов, ссылка на раздел с корневой страницы, локализация как у остальных разделов. Явно исключены пагинация, фильтры, сортировка, любые действия над чатами и изменение контракта API.
- Функциональности: одна новая capability `plugins/telegram-chat-list/web-ui`; существующие capability (`plugins/telegram-chat-list/http-api`, `plugins/telegram-chat-list/chat-tracking`, `plugins/web-ui/*`) не меняются — ссылка на корневой странице добавляется существующим механизмом, а состав ссылок корневой страницы ни одним требованием не описан, поэтому требование о доступности раздела с корневой страницы предложено закрепить в новой capability.
- `cow validate --change chat-list-ui --json`: `valid: true`; остались только info о заблокированных артефактах следующих фаз и warning `DELTA_MISSING` (дельты specs пишутся на фазе plan).
- Размер `normal`, сложность реализации и ревью обычная: в репозитории есть прямой прецедент добавления UI-плагина (коммит `69745f3`, cron web-ui), контракты и миграции не затрагиваются, риск ограничен сборкой клиентской части и правкой корневой страницы оболочки.
