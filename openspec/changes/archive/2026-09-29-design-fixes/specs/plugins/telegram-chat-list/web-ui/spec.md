## MODIFIED Requirements

### Requirement: Отображение незаданных значений и пустого списка
Если поле записи (`login`, `firstName`, `lastName`) возвращено как `null`, раздел SHALL отображать в соответствующей ячейке прочерк вместо пустого места. Если список чатов пуст, вместо таблицы SHALL отображаться локализованное сообщение об отсутствии записей серым текстом с выравниванием по центру.

#### Scenario: Запись с незаданными полями
- **WHEN** в списке есть запись, у которой `login`, `firstName` или `lastName` равны `null`
- **THEN** в соответствующих ячейках таблицы отображается прочерк

#### Scenario: Пустой список чатов
- **WHEN** HTTP API вернул пустой список чатов
- **THEN** вместо таблицы отображается центрированное серое сообщение об отсутствии сохранённых чатов

### Requirement: Ошибка загрузки списка чатов
Если запрос списка чатов завершился ошибкой, раздел SHALL показать пользователю уведомление об ошибке загрузки данных и локализованное сообщение об ошибке серым текстом с выравниванием по центру; таблица с частичными или ранее загруженными данными SHALL не отображаться.

#### Scenario: Запрос списка завершился ошибкой
- **WHEN** запрос `/api/telegram-chat-list/web-api/list` завершается ошибкой
- **THEN** пользователю показываются уведомление и центрированное серое сообщение об ошибке загрузки, а таблица чатов не отображается
