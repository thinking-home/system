## Ручные проверки

Окружение: локальный PostgreSQL и запущенное приложение из `ThinkingHome.Console` по правилам `project.testing`. Для сценариев ошибок и пустых ответов подменить ответы указанных API через прокси или DevTools. Проверить каждую страницу в светлой и тёмной теме.

### Pending-состояние асинхронных списков

- [ ] Удержать обязательные запросы `/api/scripts/web-api/list`, `/api/scripts/web-api/subscription/list` вместе с запросами сценариев и событий, `/api/cron/web-api/list`, `/api/telegram-chat-list/web-api/list` и `/api/tmp/pigs`. Пока запрос не завершён, на каждом соответствующем маршруте сохраняется loading; не показаны empty-сообщение, error-сообщение или таблица/список. После успешного ответа `[]` loading заменяется только empty-сообщением.

### plugins/scripts/web-ui › Состояния списков сценариев и подписок

- [ ] `Пустой список сценариев`: вернуть `[]` из `/api/scripts/web-api/list`. На `/scripts` видно центрированное серое сообщение об отсутствии сценариев; заголовок и обе кнопки действий доступны.
- [ ] `Ошибка загрузки списка сценариев`: завершить `/api/scripts/web-api/list` ошибкой. На `/scripts` видно центрированное серое сообщение об ошибке и уведомление об ошибке; заголовок и действия видны.
- [ ] `Пустой список подписок`: удержать начальные запросы до проверки loading, затем вернуть `[]` из `/api/scripts/web-api/subscription/list` и успешные данные остальных запросов. На `/scripts/subscriptions` видно центрированное серое сообщение об отсутствии подписок; заголовок, ссылка возврата и кнопка добавления видимы и доступны.
- [ ] `Ошибка загрузки страницы подписок`: по очереди завершить ошибкой запросы подписок, сценариев и зарегистрированных событий. В каждом случае показаны одно page-level сообщение об ошибке и одно уведомление; содержимое списка не показано, а заголовок, ссылка возврата и кнопка добавления видимы и доступны.
- [ ] `Одновременная ошибка загрузки страницы подписок`: одновременно завершить ошибкой минимум два из трёх обязательных начальных запросов. Показаны одно page-level сообщение об ошибке и ровно одно уведомление; список не отображается, а заголовок, ссылка возврата и кнопка добавления доступны.

### plugins/scripts/web-ui › Пустое состояние редактора meta-фильтра

- [ ] `В фильтре нет правил`: открыть шторку новой подписки, не выбирать пользовательское событие и не добавлять строки. В области meta-фильтра видно центрированное серое сообщение об отсутствии правил; действие добавления строки доступно.
- [ ] `Добавление первого правила`: из пустого состояния добавить строку. Сообщение исчезает, показана редактируемая строка правила и действие добавления остаётся доступным.

### plugins/scripts/web-ui › Заголовок шторки подписки
