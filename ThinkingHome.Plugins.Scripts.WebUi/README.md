# ScriptsWebUiPlugin

Добавляет в веб-интерфейс разделы для работы со сценариями: список сценариев, редактор и подписки на сценарные события.

Данные плагин берет через [HTTP API сценариев](../ThinkingHome.Plugins.Scripts.WebApi), поэтому вместе с ним должен быть подключен плагин `ThinkingHome.Plugins.Scripts.WebApi`.

## Разделы

### `/scripts`

Список сохраненных сценариев. Из него можно перейти к редактированию сценария, создать новый и удалить существующий.

### `/scripts/edit`

Редактор сценария. Адрес открывает редактор нового сценария; чтобы открыть сохраненный, нужно указать его id: `/scripts/edit?id={id}`.

В редакторе задается название сценария и его текст, а сохраненный сценарий можно выполнить и увидеть значение, которое он вернул.

Выполняется сохраненный вариант сценария, поэтому пока в редакторе есть несохраненные правки, кнопка запуска недоступна. Ошибку выполнения сценария сервер на клиент не возвращает: сценарий, завершившийся ошибкой, вернет `null`, а текст ошибки будет записан в лог системы.

### `/scripts/subscriptions`

Подписки сценариев на [сценарные события](../ThinkingHome.Plugins.Scripts/README.md#сценарные-события): список подписок, добавление и удаление (с подтверждением). Редактирование подписки не предусмотрено — вместо него подписка удаляется и создается заново.

При добавлении подписки название события выбирается из списка зарегистрированных событий (со строкой поиска), а фильтр по meta задается таблицей пар «ключ-значение». Если выбрано пользовательское событие, первая строка фильтра закреплена: ее ключ — имя пользовательского события (константы приходят с сервера из [`/api/scripts/web-api/events/list`](../ThinkingHome.Plugins.Scripts.WebApi/README.md#apiscriptsweb-apieventslist)), удалить эту строку или поменять ее ключ нельзя.

Подписка на событие, которого нет в реестре (например, его плагин отключен), продолжает отображаться в списке — рядом с названием события показывается пометка «не зарегистрировано».

## Редактор

Текст сценария редактируется в [CodeMirror](https://codemirror.net/) с подсветкой синтаксиса JavaScript. Редактор поддерживает светлую и темную цветовые схемы: он переключается вместе со всем интерфейсом.

Текст набирается шрифтом [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (SIL Open Font License 1.1). Шрифт лежит в ресурсах плагина и отдается сервером, поэтому интернет для него не нужен.
