# Клиент источников пакетов

Клиент получает версии, метаданные и архивы NuGet V3. Он не устанавливает плагины, не разрешает граф зависимостей и не изменяет appsettings. Метаданные, включая nuspec, доступны в результате `DownloadAsync` для последующего построения графа.

## Конфигурация

Скопируйте и настройте [sources.example.json](sources.example.json):

```json
{
  "sources": ["https://api.nuget.org/v3/index.json"]
}
```

Каждый адрес — HTTP(S) service index. Порядок в массиве определяет приоритет. Один источник может содержать плагины и обычные библиотеки. Можно добавить адрес локального [сервера репозитория](../ThinkingHome.Repository/README.md), например `http://127.0.0.1:5088/v3/index.json`. Неизвестные поля JSON, повтор источника и URL другой схемы отклоняются. Старые поля `pluginSources` и `librarySources` удалены и тоже отклоняются. Учётные данные в URL не поддерживаются.

Первый источник, где найден package ID, закрепляется за этим запросом независимо от типа пакета. Список версий берётся из него; отсутствие нужной версии не переключает клиента на менее приоритетный источник. Это исключает смешивание версий одного ID из разных источников без явного изменения конфигурации.

404 списка версий означает отсутствие пакета и позволяет перейти к следующему источнику. Ошибки HTTP, сети и формата ответа завершают операцию; они не считаются отсутствием пакета. Отсутствие самого service index также является ошибкой конфигурации источника.

При скачивании клиент проверяет ту же ID/версию во всех остальных источниках. Одинаковые байты допустимы; разные SHA-512 означают конфликт и отказ. Недоступность дополнительного источника тоже останавливает проверку, поскольку отсутствие конфликта не подтверждено.

Категория определяется после скачивания конкретной версии: `PackageMetadata.Read(bytes)` читает `ThinkingHome.Plugin.*` из метаданных базовых DLL в `lib/net10.0/` без загрузки сборок и выполнения кода. Корректный манифест означает плагин; отсутствие маркера — обычную библиотеку, включая пакеты только с native-ресурсами. Повреждённый, неполный, неизвестный или дублирующийся маркер, несколько манифестов и несовпадение identity с nuspec вызывают ошибку. Имя пакета, теги NuGet и адрес источника не определяют категорию. Формат манифеста описан в [документации упаковки](../ThinkingHome.Packaging/README.md).

Планировщик использует эту категорию для областей загрузки и допускает только плагины в корне установки. Категория относится к выбранной версии в текущей ветви поиска: возврат к другой версии повторно учитывает её метаданные. Ошибка сети или повреждённый пакет останавливает операцию, а не превращает пакет в библиотеку.

## Команды

Из корня репозитория:

```powershell
dotnet build ThinkingHome.PackageSources/ThinkingHome.PackageSources.csproj -m:1 -p:UseSharedCompilation=false
dotnet run --project ThinkingHome.PackageSources/ThinkingHome.PackageSources.csproj --no-build -- versions ThinkingHome.PackageSources/sources.example.json Newtonsoft.Json
dotnet run --project ThinkingHome.PackageSources/ThinkingHome.PackageSources.csproj --no-build -- download ThinkingHome.PackageSources/sources.example.json Newtonsoft.Json 13.0.3 artifacts/downloads
```

Для плагина используются те же команды с его ID и версией. Архив должен быть опубликован в одном из настроенных источников и содержать манифест ThinkingHome; наличие старого пакета с подходящим именем на nuget.org само по себе недостаточно.

Команда download проверяет identity архива и автоматически читает метаданные плагина при наличии маркера. Архив появляется в выходной папке только после успешной проверки, через временный файл. Существующий файл не перезаписывается. Имена архивов формируются из проверенных ID и нормализованных версий; конфигурация установки не создаётся.

## API

- `FindAsync(id)` возвращает выбранный service index, обнаруженный PackageBaseAddress и версии.
- `DownloadAsync(id, version)` возвращает источник, метаданные, исходные байты и SHA-512. `Metadata.Plugin` содержит манифест плагина или `null` для библиотеки.
- `DownloadLockedAsync(source, id, version)` скачивает точную версию из записанного в lock источника, независимо от нового приоритета. Источник должен присутствовать в `sources`. Сравнение с хешем и категорией из lock выполняет менеджер пакетов.
- `DownloadToAsync(...)` сохраняет проверенный архив без перезаписи существующего файла.

HttpClient передаётся вызывающей стороной, что позволяет настраивать сеть и тестировать ответы. Каждый запрос ограничен 60 секундами, включая чтение тела; поддерживается CancellationToken. JSON-ответ ограничен 4 MiB, архив — 64 MiB. Полный обход распакованного архива ограничен 256 MiB. В минимальном профиле HTTP-запросы реализованы непосредственно через HttpClient, версии нормализуются библиотекой NuGet.Versioning.

## Проверки

Тесты входят в ThinkingHome.Packaging.Tests. Проверяются общий источник для плагинов и библиотек, определение категории без выполнения кода, отклонение повреждённых метаданных и старой конфигурации, приоритеты, обработка 404 и ошибок сервера, конфликт содержимого, нормализация версии и сохранение файлов без перезаписи. Сквозные тесты используют настоящий локальный HTTP-сервер с пакетами обоих типов: CLI устанавливает и восстанавливает плагин с библиотечной зависимостью, хост запускает установленные HTTP-плагины. Тесты не требуют внешней сети.
