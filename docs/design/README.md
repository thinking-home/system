# Дизайн Thinking Home

Утверждённый вариант от 17 октября 2026 года: строчный `thinking home`, первые две буквы на плашке. Полная форма основана на Nunito Sans 600, пиктограмма - на Nunito Sans 700 (вариант A).

## Просмотр

- [Образцы всех шести состояний](preview.html) - автономная HTML-страница, не требует сети или шрифтов.
- [PDF-превью](preview.pdf) - шесть страниц, построенных из финальных SVG.
- [Манифест SVG](manifest.json).

## Готовые файлы

| Назначение | SVG | PNG |
| --- | --- | --- |
| Полный логотип | [assets/logo/svg](assets/logo/svg) | [assets/logo/png](assets/logo/png) |
| Пиктограмма | [assets/icon/svg](assets/icon/svg) | [assets/icon/png](assets/icon/png) |
| Favicon и иконки устройств | [favicon](favicon) | В той же папке |

SVG содержит контуры букв, не содержит внешних ресурсов и не требует шрифта. У всех файлов прозрачный внешний фон. В цветных версиях буквы на плашке белые; в `mono` и `inverse` они вырезаны маской и показывают фон носителя.

Названия файлов соответствуют состояниям:

| Состояние | Плашка | Остальной текст | Назначение |
| --- | --- | --- | --- |
| `teal-light` | `#005B6B` | `#20232A` | Бирюзовый на светлом фоне |
| `teal-dark` | `#076B7B` | `#F5F7FB` | Бирюзовый на тёмном фоне |
| `blue-light` | `#1E47B3` | `#20232A` | Синий на светлом фоне |
| `blue-dark` | `#2B55C3` | `#F5F7FB` | Синий на тёмном фоне |
| `mono` | `#111111` | `#111111` | Однокрасочный на светлом фоне |
| `inverse` | `#FFFFFF` | `#FFFFFF` | Однокрасочный на тёмном фоне |

Эталонные фоны в превью: белый `#FFFFFF`, тёмный `#171C25`, для монохромной инверсии `#111111`. Ни бирюзовый, ни синий не объявлен единственным основным цветом: утверждены оба.

PNG полного логотипа: ширина **256, 512, 1024, 2048 px**, высота пропорциональная. Имя PNG - его ширина. PNG пиктограммы: **16, 24, 32, 48, 64, 96, 128, 180, 192, 256, 512 px**. Имя - сторона квадрата. Для веб-интерфейса предпочтителен SVG; для растра на экране 2× используйте PNG вдвое больше отображаемого размера.

## Favicon

Подготовлены два адаптивных SVG: `teal-adaptive.svg` и `blue-adaptive.svg`. Они автоматически переключают оттенок плашки по `prefers-color-scheme`. Также есть по одному ICO для каждого цветового состояния (`teal-light`, `teal-dark`, `blue-light`, `blue-dark`), каждый включает **16, 32 и 48 px**. PNG: 16/32/48 для favicon, 180 для Apple touch icon, 192/512 для иконок приложения.

Пример для бирюзового семейства (пути предполагают копирование файлов в `/brand/`):

```html
<link rel="icon" href="/brand/teal-light.ico" sizes="16x16 32x32 48x48">
<link rel="icon" href="/brand/teal-adaptive.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/brand/teal-light-180.png">
```

ICO не переключается автоматически между темами. Для синего семейства замените `teal` на `blue`. Из этих двух альтернатив следует подключать одно семейство. Иконки с прозрачным фоном не являются maskable-иконками.

## Зафиксированная геометрия

- Полный логотип: Nunito Sans 600; трекинг `-0.015 em`.
- Дополнительный интервал после `th`: `0.08 em`; правое поле плашки `0.035 em`, левое `0.109 em` (базовое `0.055 em` + оптическая компенсация `0.054 em`, уменьшенная на 40%); скругление `0.14 em`.
- Вертикальная геометрия плашки сохранена из утверждённого браузерного образца; измерения при кегле 100 находятся в [source/geometry.json](source/geometry.json).
- Пиктограмма A: Nunito Sans 700, кегль `10.5 px` при стороне 16 px, радиус 3 px. Буквы центрируются по видимым вертикальным границам, затем поднимаются на 0.5 px; горизонтальная поправка +0.2 px. Все размеры масштабируются пропорционально.
- Не растягивать по одной оси, не менять шрифт и внутренние интервалы. SVG viewBox включает только технический запас; внешнее свободное поле задаётся макетом. Минимальный размер полного логотипа и обязательное охранное поле отдельно не утверждены.

## Исходники и повторная сборка

Начертания Google Fonts сохранены в [source/fonts](source/fonts) вместе с лицензией SIL OFL 1.1. Эти файлы нужны только для генерации, а не для использования SVG. Дата загрузки - 17.10.2026; источник: `https://fonts.googleapis.com/css2?family=Nunito+Sans:wght@600;700`. Версия семейства в URL Google Fonts - v19.

```sh
python -m pip install -r tools/requirements.txt
npm install
npx playwright install chromium
python tools/build_vectors.py
node tools/build_previews.cjs
python tools/build_favicons.py
python tools/validate_assets.py
```

Для установленного Chromium/Edge можно задать `CHROME_PATH`. PDF и HTML генерируются из SVG и не требуют сети. При обновлении исходного шрифта геометрию и визуальное соответствие нужно проверить заново. PNG и favicon проверяются при нативном экранном размере: масштаб PDF не воспроизводит растр браузерной вкладки.
