*ThinkingHome.Plugins.TelegramChatList.WebUi*

# TelegramChatListWebUiPlugin

Добавляет в веб-интерфейс раздел со списком чатов Telegram, сохранённых плагином [TelegramChatList](../ThinkingHome.Plugins.TelegramChatList).

Данные плагин берет через [HTTP API списка чатов](../ThinkingHome.Plugins.TelegramChatList.WebApi), поэтому вместе с ним должен быть подключен плагин `ThinkingHome.Plugins.TelegramChatList.WebApi`.

## Разделы

### `/telegram-chat-list`

Таблица сохранённых чатов: для каждой записи показаны `id`, `chatId` (идентификатор чата в Telegram), `login`, `firstName`, `lastName` и `date` (дата последнего сообщения, в локальном формате браузера). Записи отображаются в порядке, в котором их вернул HTTP API — сортировку, фильтры и пагинацию раздел не добавляет.

Раздел доступен только для просмотра: создание, изменение и удаление записей в нём не предусмотрены.

Незаданные значения `login`, `firstName` и `lastName` отображаются прочерком. Если список чатов пуст, вместо таблицы показывается сообщение об отсутствии сохранённых чатов. Если запрос списка завершился ошибкой, пользователю показывается уведомление об ошибке загрузки, а таблица не отображается.
