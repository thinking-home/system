*ThinkingHome.Plugins.Cron.WebUi*

# CronWebUiPlugin

Добавляет в веб-интерфейс раздел для управления расписанием планировщика задач.

Данные плагин берет через [HTTP API планировщика](../ThinkingHome.Plugins.Cron.WebApi), поэтому вместе с ним должен быть подключен плагин `ThinkingHome.Plugins.Cron.WebApi`.

## Разделы

### `/cron`

Список записей расписания, добавление, редактирование (открывается кликом по названию записи) и удаление (с подтверждением).

В форме записи время запуска задается [выражением cron](../ThinkingHome.Plugins.Cron/README.md#формат-выражения) из пяти сегментов (минута, час, день, месяц, день недели) — например, `*/5 * * * *` для запуска каждые 5 минут. Также у записи задаются название (обязательно), имя [пользовательского сценарного события](../ThinkingHome.Plugins.Scripts/README.md#пользовательские-события), которое будет генерироваться при запуске (необязательно), и признак активности.

Под полем выражения и в списке записей выводится его человекочитаемое описание («Каждые 5 минут») на языке системы. Проверку формата и описание выполняет сервер (эндпоинт [`describe`](../ThinkingHome.Plugins.Cron.WebApi/README.md#apicronweb-apidescribe)): при вводе выражения клиент запрашивает их с небольшой задержкой после паузы в наборе. На клиенте нет ни знаний о поддерживаемых языках, ни библиотек работы с cron — при добавлении нового языка в систему этот плагин менять не нужно.

Выключенные записи отмечены в списке пометкой «выключена».
